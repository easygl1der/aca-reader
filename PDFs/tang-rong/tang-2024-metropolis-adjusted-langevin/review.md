# 论文审稿意见

## 论文概述

Tang 与 Yang 的这篇论文研究了 Metropolis-Adjusted Langevin 算法（MALA）用于贝叶斯后验（或伪后验）抽样的计算复杂度。核心问题是：在后验分布可能非光滑、非对数凹的情况下，MALA 的混合时间如何依赖于参数维度 $d$ 和条件数 $\kappa$？作者引入了 **$s$-conductance profile** 这一新技术，在无需对目标分布施加光滑或强对数凹性假设的条件下，证明了 MALA 达到最优的 $O(d^{1/3})$ 维度依赖（经 burn-in 后），且条件数依赖为线性。同时给出了匹配的下界，并将理论应用于光滑与非光滑 Gibbs 后验（包括贝叶斯分位数回归）。

## 总体评价

**贡献与创新性**：本文填补了 MALA 混合时间理论中的一个重要空白。已有文献中，最优 $d^{1/3}$ 混合时间仅在极度规则的乘积分布（如标准高斯）下得到（Chewi et al., 2021），而本文通过利用贝叶斯后验的渐近高斯性（Bernstein-von Mises 定理），将这一最优维度依赖推广到一大类实际感兴趣的后验分布——包括非光滑和非对数凹的情形。这一贡献具有重要的理论与实践意义：它从统计大样本理论的角度解释了为什么梯度信息能在 MALA 中带来比随机游走（MRW）更好的维度依赖（$d^{1/3}$ vs $d$）。

**技术深度**：论文的技术含量很高。核心新工具——$s$-conductance profile——是介于经典 conductance 与 Chen et al. (2020) 的 conductance profile 之间的精细分析技术，能够在不需要高概率集为凸集的前提下改进 warm-start 参数依赖（从 $\log M_0$ 到 $\log\log M_0$），且不恶化维度依赖。证明中综合运用了经验过程理论（chaining、peeling、localization）处理非光滑损失函数，并通过对数等周不等式的扰动分析建立高斯目标与一般目标之间的桥梁。附录中的下界证明也经过了仔细的 dimension-$\kappa$ 依赖跟踪。

**主要优势**：
1. 将最优 $d^{1/3}$ 混合时间从极度受限的乘积分布推广到一般贝叶斯后验（包括伪后验/Gibbs 后验），理论覆盖面显著扩大。
2. 引入 $s$-conductance profile，提供了比已有技术更精细的混合时间分析工具，具有独立的方法论价值。
3. 理论结果与数值实验（贝叶斯线性回归、分位数回归）相互印证，实验设计合理，对不同维度-样本量关系的考察揭示了光滑性对收敛速度的影响。
4. 对预条件矩阵（preconditioning matrix）的分析具有实践指导意义，表明利用 Fisher 信息矩阵的估计可以改善条件数和混合时间。

**主要不足**：
1. **维度-样本量约束**：定理要求 $d \leq c n^{\kappa_1}/\log n$，其中 $\kappa_1$ 取决于损失函数的光滑性参数 $\beta_1$。对于非光滑情形（如分位数回归，$\beta_1 = 1/2$），$\kappa_1$ 较小，意味着需要相对更大的样本量才能保证 $d^{1/3}$ 混合时间。这一约束在论文中以隐式方式呈现，对读者理解何时可以期望达到最优收敛有一定障碍。
2. **Warm start 的构造**：论文指出需要 $\log M_0 \leq d^{1/3}$ 来达到最优混合时间，但如何对一般非对数凹分布高效构造满足此条件的 warm start 并未给出通用算法，仅在贝叶斯框架下通过渐近高斯性加以说明。这一问题被作者列为未来方向是合理的，但削弱了理论结果的"即用性"。
3. **对 ULA 的处理**：论文主要关注 MALA（带 MH 校正），而对无校正 Langevin 算法（ULA）的讨论较少。ULA 在某些场景下更实用，其误差界（$O(\sqrt{dh})$ 远离平稳分布）虽在第 2 节有所提及，但未像 MALA 那样给出系统的比较分析。

**结论**：这是一篇理论扎实、创新显著的高质量论文。建议优先发表（Minor Revision）。核心贡献——$s$-conductance profile 技术和将最优 $d^{1/3}$ 混合时间拓展到非光滑贝叶斯后验——具有持久的学术价值。建议要求作者在修订时更明确地说明维度-样本量约束的直观含义，以及 warm-start 构造的实际可行建议。
