\section{摘要}\label{sec:abstract}

本文综述 Tang-Rong 系列工作（2021--2025），涵盖 Rong Tang 与 Yun Yang
等在流形统计学习领域的系列研究。该系列围绕三个核心问题展开：
（1）低维流形上分布估计的统计极限是什么？
（2）深度生成模型能否隐式自适应流形结构？
（3）如何在流形约束下进行稳健的贝叶斯推断和高效 MCMC？

系列包含 9 篇论文，发表于 COLT、Annals of Statistics、JRSS B、ICML、AISTATS 等
顶级会议与期刊，并延伸至分布回归与条件扩散模型的 arXiv 工作。
整个系列在极小极大理论、稳健贝叶斯推断和扩散模型自适应三个维度上建立了
从理论奠基到方法验证、再到算法优化的完整体系。
本文对各论文进行批判性评述，分析其技术贡献与局限性，
梳理三条研究主线之间的内在联系，并提出若干开放问题。

% ----------------------------------------------------------
\section{研究脉络总览}\label{sec:overview}

现代高维数据（图像、文本、点云）的本质特征是：环境维度 $D$ 巨大，
但有效信息维度 $d \ll D$，数据通常位于某个未知低维流形上。
这一观察催生了三个根本性问题：

\begin{enumerate}
    \item \textbf{统计极限}：当数据支撑于未知低维流形时，
          分布估计的极小极大速率是什么？$D$ 是否必然出现在速率中？
    \item \textbf{自适应机制}：深度生成模型（VAE、GAN、扩散模型）
          在实践中表现出色，但其隐式自适应流形结构的理论机制尚不清晰。
    \item \textbf{贝叶斯推断}：当参数自然地取值于黎曼流形时，
          如何进行稳健的贝叶斯推断？后验分布的渐近行为是什么？
\end{enumerate}

该系列可划分为三条交织演进的研究主线：
\textbf{主线一}（极小极大 $\to$ 深度验证）：
\citep{tang2022minimax} 建立极小极大理论框架；
\citep{tang2023lowdim} 将理论具体化为 MLDMAE 方法；
\citep{tang2025regression} 推广至分布回归设定。

\textbf{主线二}（VAE $\to$ 扩散模型自适应）：
\citep{tang2021vae} 建立 VAE 的 Excess Risk Bound；
\citep{tang2024diffusion} 证明扩散模型同样自适应流形；
\citep{tang2025conditional} 将最优性推广至条件扩散模型。

\textbf{主线三}（稳健贝叶斯 $\to$ 高效 MCMC）：
\citep{tang2023robust} 建立黎曼 BvM 定理与 RRWM 算法；
\citep{tang2024mala} 利用 BvM 性质证明 MALA 最优混合时间。

\section{主线一：从极小极大理论到深度模型验证}\label{sec:line1}

\subsection{\citep{tang2022minimax}：极小极大理论的奠基}\label{sec:ch0-annals2022}

\textbf{论文信息}：Annals of Statistics, 2022, Vol.50, No.4, 2197--2216.

\textbf{创新性}：首次建立了未知子流形上分布估计在对抗损失下的
完整极小极大理论。核心发现是三类不同收敛机制的识别：
参数机制（$n^{-1/2}$）、密度估计机制
（$n^{-(\alpha+\gamma)/(2\alpha+d)}$）和流形估计机制
（$n^{-\beta\gamma/d}$），三者取最大值构成最终速率。
\textbf{关键发现：环境维度 $D$ 完全不出现在速率指数中。}

\textbf{技术贡献}：引入单位分解（Partition of Unity）技术，
构造了能够覆盖无全局参数化流形的估计器，
突破了单编码器 VAE/GAN 的根本局限。
下界证明综合运用 Fano 不等式、Varshamov-Gilbert 引理、
经验过程理论（chaining、peeling、localization）和 Poincaré 不等式。

\textbf{局限性}：

\begin{itemize}
    \item 估计器构造涉及小波截断、Lepski 自适应等复杂步骤，
          未给出具体算法实现——这是一篇"理论导向"而非"方法导向"的工作。
    \item 仅考虑无噪声观测；噪声情形下收敛速率急剧下降至仅对数级。
    \item 流形光滑阶 $\beta$ 和密度光滑阶 $\alpha$ 须已知或通过额外假设获得。
\end{itemize}

\textbf{在系列中的地位}：
\citep{tang2022minimax} 是整个系列的理论基石，
为 \citep{tang2023lowdim}、\citep{tang2024diffusion}、
\citep{tang2025regression} 中具体生成模型的分析提供了理论参照系。

% ----------------------------------------------------------
\subsection{\citep{tang2023lowdim}：MLDMAE 方法}\label{sec:ch0-icml2023}

\textbf{论文信息}：ICML, 2023.

\textbf{创新性}：提出混合潜在分布匹配自编码器（MLDMAE）方法，
利用 $K$ 个局部编码器-解码器对分别学习流形局部区域的参数化，
通过单位分解函数 $\rho_k$ 实现光滑拼接。
\textbf{核心发现：多编码器/解码器结构在流形分布估计中是必要的。}
在 1-Wasserstein 距离下达极小极大最优（至多对数因子）。

\textbf{技术贡献}：将 \citep{tang2022minimax} 的理论极小极大框架
转化为可计算的深度学习方法，验证了单位分解技术在深度学习中的可实现性。

\textbf{局限性}：

\begin{itemize}
    \item 聚类数 $K$ 的选择缺乏自适应理论指导，
          仅通过实验说明 $K\approx 10$ 对 MNIST 有效。
    \item 当 $\alpha > \beta-1$ 时，最优速率是否仍然保持极小极大最优，
          论文仅提及但未严格证明。
    \item 局部块之间的重叠区域在理论上没有得到充分分析。
\end{itemize}

% ----------------------------------------------------------
\subsection{\citep{tang2025regression}：分布回归的极小极大速率}\label{sec:ch0-arxiv2025a}

\textbf{论文信息}：arXiv:2501.00001, 2025.

\textbf{创新性}：在三类层次递进的设定下系统建立了极小极大下界，
并提出融合对抗学习（IPM 度量）与同步最小二乘的混合估计量。
$\gamma$-Hölder IPM $d_\gamma$ 统一了全变差距离（$\gamma=0$）
和 1-Wasserstein 距离（$\gamma=1$）。

Regime 3（协变量依赖响应空间）揭示了 $d_X, d_Y, \beta_X, \beta_Y$
等几何参数如何共同决定收敛速率。

\textbf{局限性}：

\begin{itemize}
    \item 三层 Regime 的下界证明复杂，
          但上界中 $\frac{\alpha_Y}{\alpha_X}\cdot d_X$ 项的出现略显 ad hoc，
          缺乏几何直觉。
    \item 提出的混合估计量在 $\gamma\neq 0,1$ 时是否仍然可计算
         （如何实现 IPM 的判别器优化？）并未讨论。
    \item 条件流形族 $\mathcal{M}_{Y|x}$ 随 $x$ 光滑变化的假设较强，
          在实际应用中难以验证。
\end{itemize}

\section{主线二：从 VAE 到扩散模型自适应理论}\label{sec:line2}

\subsection{\citep{tang2021vae}：VAE 的 Excess Risk Bound}\label{sec:ch0-colt2021}

\textbf{论文信息}：COLT, 2021.

\textbf{创新性}：为 VAE 型生成模型提供了首个关于 Excess Risk 的
非渐近上界，揭示了 VAE 隐式自适应低维流形结构的机制——
潜在空间维数与流形本征维数的关系是关键。

\textbf{局限性}：

\begin{itemize}
    \item 假设条件依赖于解码器族和编码器族的逼近能力，
          在实际应用中的可验证性有待进一步讨论。
    \item VAE 的 posterior collapse 问题在理论上没有得到解释，
          限制了理论结果的实践指导意义。
    \item Excess Risk Bound 的速率可能不是最优的，
          与 \citep{tang2022minimax} 的极小极大速率存在差距。
\end{itemize}

% ----------------------------------------------------------
\subsection{\citep{tang2024diffusion}：扩散模型自适应流形结构}\label{sec:ch0-aistats2024}

\textbf{论文信息}：AISTATS, 2024.

\textbf{创新性}：系统证明了\textbf{两类扩散模型（Langevin 扩散
和正向--反向扩散）的分布估计收敛速率仅依赖于数据的本征维度 $d$
而非环境维度 $D$}——
这是该论文最重要的理论发现，建立了
"实践有效的工具 $\Leftrightarrow$ 理论最优的方法"这一对应关系。

\textbf{技术贡献}：

\begin{itemize}
    \item \textbf{Langevin 扩散分支}：通过 Gaussian 平滑
          $p_\sigma(x) = \int p_{\mathrm{data}}(y)\phi_\sigma(x-y)\,\mathrm{d}y$
          使密度函数在任意时刻 $t>0$ 关于 Lebesgue 测度绝对连续，
          关键改进为只需分数函数的四阶矩误差（而非 $L_\infty$
          或矩母函数误差）即可控制分布估计误差。
    \item \textbf{正向--反向扩散分支}：构造了时间分段常数的
          神经网络架构 $\mathcal{S}_{\mathrm{NN}}$ 逼近时变分数函数，
          在 1-Wasserstein 距离下达极小极大最优速率
          $\frac{1}{\sqrt{n}}\;\vee\;n^{-\frac{\alpha+1}{2\alpha+d}}$。
    \item 通过 Girsanov 定理建立了分数估计误差与分布估计误差之间的联系，
          是连接 SDE 理论与统计学习的核心技术。
\end{itemize}

\textbf{深层机制}：正向扩散天然地通过高斯噪声填充了流形的管状邻域，
从而回避了奇异分布（流形支撑分布）的困难。

\textbf{局限性}：

\begin{itemize}
    \item 神经网络架构（时间分段常数）过于简化，
          距实际使用的 ResNet、U-Net 等架构仍有较大差距。
    \item 各向同性高斯噪声可能"稀释"流形结构——
          论文提及但未给出严格的量化分析。
    \item 分段数 $J$ 依赖于未知的光滑度参数 $\alpha$，实践中难以选择。
\end{itemize}

\textbf{与系列的关系}：
\citep{tang2022minimax} 提供极小极大目标；本篇证明扩散模型能够达到该目标。

% ----------------------------------------------------------
\subsection{\citep{tang2025conditional}：条件扩散模型的最优性}\label{sec:ch0-arxiv2025b}

\textbf{论文信息}：arXiv:2501.00002, 2025 (joint with Lizhen Lin).

\textbf{创新性}：首次建立了条件扩散模型的流形自适应理论，
在两种场景下均达到极小极大最优收敛速率：
（1）经典密度回归设定（基于全变差度量）：
推广了已有文献结果（现有文献仅覆盖 $\alpha_X\in[0,1]$ 情形）；
（2）高维回归设定（基于 Wasserstein 度量）：
估计误差仅依赖内在维度 $(d_X,d_Y)$ 而非环境维度 $(D_X,D_Y)$。

\textbf{局限性}：

\begin{itemize}
    \item 缺乏对条件生成模型与 \citep{tang2025regression} 条件分布回归理论
          之间关系的讨论。
    \item 条件扩散模型中的 classifier-free guidance 等实践技术
          的理论解释尚未涉及。
    \item 条件分数函数的估计需要额外的条件生成模型架构，计算成本较高。
\end{itemize}

\section{主线三：从稳健贝叶斯到高效 MCMC}\label{sec:line3}

\subsection{\citep{tang2023robust}：黎曼子流形上的稳健贝叶斯推断}\label{sec:ch0-jrssb2023}

\textbf{论文信息}：JRSS B, 2023, Vol.85, No.4, 1079--1103
(joint with Anirban Bhattacharya and Debdeep Pati).

\textbf{创新性}：提出 Bayesian RPETEL 框架——
无需正确指定似然函数的模型自由贝叶斯推断框架，展现三重稳健性：
（1）无需正确指定似然函数即可提供自动校准的不确定性量化；
（2）即使欧氏风险最小化器不在流形上，后验中心仍能接近
流形上的风险最小化器；
（3）在正确设定下与标准贝叶斯后验渐近等价而不损失效率。

\textbf{核心理论贡献}：\textbf{黎曼流形上的 Bernstein-von Mises (BvM) 定理}。
通过将后验分布投影到流形切空间并利用局部坐标变换，
成功将欧氏空间中的分析工具推广到流形 setting，
证明了后验分布在切空间上的投影渐近正态——
这是本文最重要的理论贡献。

\textbf{计算贡献}：提出黎曼随机游走 Metropolis (RRWM) 算法，
证明了混合时间仅依赖流形内在维度 $d$ 而非环境维度 $D$。

\textbf{局限性}：

\begin{itemize}
    \item 正则性假设较强：假设流形局部为 $C^3$ 光滑，
          且要求风险函数满足二次增长条件，
          限制了在更一般流形上的应用。
    \item BvM 定理的收敛速度（到渐近正态的速率）在论文中没有给出，
          使得有限样本下的可靠性难以量化。
    \item RRWM 的 proposal 设计较为简单，在多峰分布或强非线性流形上
          可能表现不佳。
\end{itemize}

% ----------------------------------------------------------
\subsection{\citep{tang2024mala}：MALA 的最优混合时间}\label{sec:ch0-icml2024}

\textbf{论文信息}：ICML, 2024.

\textbf{创新性}：引入 $s$-conductance profile 新技术，
在无需对目标分布施加光滑或强对数凹性假设的条件下，
证明了 MALA 达到最优 $O(d^{1/3})$ 维度依赖（经 burn-in 后），
且条件数依赖为线性，给出了匹配的下界。

\textbf{技术贡献}：$s$-conductance profile 提供了介于经典 conductance
与 Chen et al. (2020) 的 conductance profile 之间的精细分析工具，
在非凸集假设下将 warm-start 参数依赖从 $\log M_0$ 改进到 $\log\log M_0$——
在高维后验分布（$M_0$ 极大）的实际场景中意义显著。

\textbf{与 \citep{tang2023robust} 的内在联系}：
\citep{tang2023robust} 建立了流形上的 BvM 定理（后验渐近正态）；
本篇则利用渐近高斯性，将 MALA 在高斯目标分布上的最优性质
桥接到一大类实际感兴趣的后验分布。

\textbf{局限性}：

\begin{itemize}
    \item 定理要求 $d \leq c n^{\kappa_1}/\log n$，对于非光滑情形
          需要相对更大的样本量才能保证 $d^{1/3}$ 混合时间。
    \item $s$-warm start 假设在实践中难以验证，
          与 MCMC "无知采样"的哲学存在张力。
    \item 没有给出实际可用的 burn-in 长度估计。
    \item 在欧氏空间建立结果，流形上的 MALA 最优混合时间是开放问题。
\end{itemize}

\section{两样本检验：独立分支}\label{sec:twosample}

\subsection{\citep{tang2023twosample}}\label{sec:ch0-aistats2023}

\textbf{论文信息}：AISTATS, 2023.

\textbf{创新性}：建立了统一的两样本检验框架，基于负 Besov 范数的
样本版本（通过截断小波展开构造），然后进行标准化处理。
核心创新是建立了负 Besov 范数与对抗损失之间的等价关系（引理 1），
从而能够同时适用于 $\ell_1$、$\ell_2$ 距离和 Wasserstein 距离等多种度量。
计算复杂度 $O(n\log n + n^{2d/(4\alpha+d)})$ 远优于 MMD 的 $O(n^2)$。

\textbf{局限性}：

\begin{itemize}
    \item 正则性假设过强：假设密度函数具有紧支撑且一致有界，
          在许多实际应用中可能难以满足。
    \item 最优截断水平 $J$ 的选择依赖于未知的光滑度参数 $\alpha$——
          如何构造对 $\alpha$ 自适应的检验仍是开放问题。
    \item Bootstrap 阈值的理论支撑不足。
\end{itemize}

\section{论文关系与技术索引}\label{sec:synthesis}

\subsection{发表时间线}\label{sec:timeline}

\begin{enumerate}
    \item \textbf{2021} --- \citep{tang2021vae}（COLT: VAE Excess Risk Bound）
    \item \textbf{2022} --- \citep{tang2022minimax}
          （Annals of Statistics: 流形极小极大框架）
    \item \textbf{2023a} --- \citep{tang2023lowdim}
          （ICML: MLDMAE 混合生成模型）
    \item \textbf{2023b} --- \citep{tang2023robust}
          （JRSS B: 流形稳健贝叶斯 + BvM）
    \item \textbf{2023c} --- \citep{tang2023twosample}
          （AISTATS: 两样本检验）
    \item \textbf{2024a} --- \citep{tang2024diffusion}
          （AISTATS: 扩散模型自适应流形）
    \item \textbf{2024b} --- \citep{tang2024mala}
          （ICML: MALA 最优混合时间）
    \item \textbf{2025a} --- \citep{tang2025regression}
          （arXiv: 分布回归极小极大速率）
    \item \textbf{2025b} --- \citep{tang2025conditional}
          （arXiv: 条件扩散模型最优性）
\end{enumerate}

\subsection{核心技术索引}\label{sec:tech-index}

\begin{enumerate}
    \item \textbf{单位分解（Partition of Unity）}：
          \citep{tang2022minimax}、\citep{tang2023lowdim} 利用此技术
          处理无全局参数化流形——
          是估计器构造的核心工具，也是区别于单编码器 VAE/GAN 的关键。

    \item \textbf{$\gamma$-Hölder IPM 框架}：
          \citep{tang2022minimax}、\citep{tang2023twosample}、
          \citep{tang2025regression} 将不同光滑度的判别器类
          统一在同一个框架下，实现多种距离度量的同时最优。
          $\gamma$ 参数在流形支撑恢复与密度估计之间引入了可调节的权衡。

    \item \textbf{Gaussian 平滑 + 四阶矩误差}：
          \citep{tang2024diffusion} 将 Langevin 扩散的分析从 $L_\infty$
          弱化到四阶矩，建立了更弱但更实用的误差条件，
          是沟通 SDE 理论与统计估计的关键技术。

    \item \textbf{时间分段神经网络架构}：
          \citep{tang2024diffusion}、\citep{tang2025conditional} 构造了
          随时间演化的神经网络架构，
          有效平衡了近时间端（$t$ 小）与远时间端（$t$ 大）的逼近精度。

    \item \textbf{$s$-conductance profile}：
          \citep{tang2024mala} 提出的马尔可夫链分析新技术，
          提供了介于经典 conductance 与 conductance profile 之间的
          精细分析工具，改进 warm-start 参数依赖。

    \item \textbf{黎曼流形 Bernstein-von Mises 定理}：
          \citep{tang2023robust} 将经典 BvM 推广到黎曼子流形 setting，
          后验分布在切空间投影上渐近正态，
          是连接贝叶斯渐近理论与 MCMC 收敛分析的桥梁。

    \item \textbf{Girsanov 定理桥梁}：
          \citep{tang2024diffusion}、\citep{tang2025conditional} 通过
          Girsanov 定理建立分数估计误差与分布估计误差之间的联系，
          是连接 SDE 理论与统计学习的核心技术。
\end{enumerate}

\section{批判性评估}\label{sec:evaluation}

\subsection{整体优势}\label{sec:strengths}

\begin{enumerate}
    \item \textbf{理论系统性极强}：
          该系列从极小极大理论出发，依次建立了深度生成模型自适应理论
          和稳健贝叶斯推断框架，三条主线相互呼应而非孤立发表。
          这种系统性在国内统计机器学习研究中较为罕见。

    \item \textbf{技术工具有原创性}：
          单位分解、$s$-conductance profile、四阶矩误差分析等
          技术工具均具有原创性贡献，而非简单照搬已有方法。

    \item \textbf{理论与实践的桥梁意识}：
          \citep{tang2023lowdim} 和 \citep{tang2024diffusion} 体现了
          将理论极小极大速率转化为具体深度学习算法的努力，
          这一点在纯理论论文中常常缺失。

    \item \textbf{顶级发表记录}：
          在五年内（2021--2025）发表了 7 篇顶级会议/期刊论文
          （COLT, Annals, JRSS B, ICML x2, AISTATS x2），
          表明该系列工作得到了国际同行的高度认可。
\end{enumerate}

\subsection{主要不足}\label{sec:weaknesses}

\begin{enumerate}
    \item \textbf{理论与实践的显著差距}：
          尽管 \citep{tang2023lowdim} 和 \citep{tang2024diffusion} 试图
          弥合理论与实践，但估计器构造（时间分段常数神经网络等）
          与实际使用的架构（U-Net, ResNet）之间仍有较大差距。
          预训练模型能否进一步改善理论速率，这一问题未被触及。

    \item \textbf{流形维数自适应缺失}：
          整个系列均假设内在维度 $d$ 已知，但实际应用中 $d$ 通常未知。
          如何构造对 $d$ 自适应的估计器，同时保持极小极大最优性，
          是该系列最大的理论缺口之一。

    \item \textbf{噪声观测情形被忽视}：
          除两样本检验外，多数论文仅考虑无噪声观测。
          噪声情形下 \citep{tang2022minimax} 的速率急剧下降（仅对数级），
          这表明当前理论与实际应用之间存在根本性断层。

    \item \textbf{计算复杂度与统计最优性未统一}：
          渐近最优的神经网络架构面临严重的计算挑战，
          但论文中对此几乎未做讨论。

    \item \textbf{与其他生成模型理论的比较不足}：
          如与变分推断的泛化理论、归一化流的统计理论等，
          缺乏有意义的比较和区分。

    \item \textbf{BvM 定理的局限性}：
          \citep{tang2023robust} 的 BvM 定理要求后验分布相对"规则"，
          对实际中常见的混合后验、退化后验等情形不适用。
\end{enumerate}

\section{开放问题与进一步阅读}\label{sec:open}

基于对 Tang-Rong 系列的批判性分析，以下问题值得进一步探索：

\begin{enumerate}
    \item \textbf{流形维数的自适应估计}：
          如何构造对 $d$ 自适应的估计器，同时保持极小极大最优性？
          是否存在类似 Lepski 方法的维数自适应技术？

    \item \textbf{噪声观测情形的多项式速率}：
          \citep{tang2022minimax} 的无噪声设定过于理想化。
          是否有方法在适度噪声假设（如有界噪声、测量误差模型）下
          恢复多项式收敛速率？

    \item \textbf{光滑性自适应}：
          极小极大速率依赖于未知的光滑度参数 $\alpha,\beta,\gamma$，
          如何构造对这些参数同时自适应的估计器？

    \item \textbf{预训练模型的理论分析}：
          实际应用中的扩散模型通常在大规模数据上预训练。
          预训练能否改善从零开始训练的极小极大速率？
          迁移学习在流形统计学习中的理论保证是什么？

    \item \textbf{流形 MCMC 的最优收敛}：
          \citep{tang2024mala} 在欧氏空间建立了 MALA 的最优混合时间；
          流形上的 MALA（黎曼流形上的 Metropolis-Hastings 算法）
          在何种条件下能够达到类似的最优依赖？

    \item \textbf{深度生成模型与其他 IPM 的结合}：
          当前的理论主要围绕 Wasserstein 距离和全变差距离展开。
          对于 MMD、Stein 差异等更一般的 IPM，
          深度生成模型能否达到相应的极小极大速率？

    \item \textbf{条件生成模型的不确定性量化}：
          \citep{tang2025conditional} 证明了条件扩散模型的条件分布估计
          最优性，但条件生成模型的后验不确定性如何刻画？
          这与 \citep{tang2023robust} 的稳健贝叶斯框架有何联系？
\end{enumerate}
