\subsection{亚组的定义}\label{sec:qa-subgroup}

\textbf{问}：什么是亚组？

\textbf{答}：亚组（subgroup）是由某个协变量（通常是二元变量 $X_i$）分割出来的子群体。例如按性别、年龄、收入等分割。亚组因果效应衡量的是在该亚组内的平均因果效应。

\subsection{恒等式 $\tau = \pi_1 \tau_1 + \pi_0 \tau_0$ 的推导}\label{sec:qa-tau-decomposition}

\textbf{问}：如何推导 $\tau = \pi_1 \tau_1 + \pi_0 \tau_0$？

\textbf{答}：利用指示函数的完备性 $\mathbb{I}(X_i=1) + \mathbb{I}(X_i=0) = 1$，将总体求和拆分为两个亚组求和，再除以对应的亚组样本量即可得到。

\subsection{为什么在 $H_{0F}$ 下 $\mathbf{Y}$ 是固定的？}\label{sec:qa-Y-fixed-under-H0F}

\textbf{问}：为什么在 Fisher's sharp null ($H_{0F}: Y_i(1) = Y_i(0)$) 下，潜在结果向量 $\mathbf{Y}$ 是固定的？

\textbf{答}：$H_{0F}$ 断言 treatment 对每个单元都没有效应，即 $Y_i(1) = Y_i(0) = Y_i$ 对所有 $i$。这意味着整个 $\mathbf{Y}(1) = \mathbf{Y}(0) = \mathbf{Y}$ 向量是确定的（固定值），不再有随机性。

在 FRT 中，我们 condition on 这个固定的 $\mathbf{Y}$，只让治疗分配 $\mathbf{Z}$ 有随机性。因此，随机化分布可以精确枚举（$M = \binom{n}{n_1}$ 种可能），不依赖任何渐近假设——这就是 FRT"有限样本精确"的本质。

\subsection{p\_frt 的 Monte Carlo 近似与修正}\label{sec:qa-pfrt-mc}

\textbf{问}：为什么 \cref{eq:mc-pvalue} 需要修正为 $\tilde p_{frt}$？

\textbf{答}：

\textbf{原始 Monte Carlo 近似}：
$$\hat{p}_{frt} = \frac{1}{R}\sum_{r=1}^R \mathbb{I}\{T(\mathbf{z}^r,\mathbf{Y}) \geq T(\mathbf{Z},\mathbf{Y})\}$$
这个估计量的问题是：当 $R$ 有限时，它可能是\textbf{反保守的}——低估真实的 p 值，导致错误地宣称显著。

\textbf{修正公式}（有限样本有效）：
$$\tilde{p}_{frt} = \frac{1 + \sum_{r=1}^R \mathbb{I}\{T(\mathbf{z}^r,\mathbf{Y}) \geq T(\mathbf{Z},\mathbf{Y})\}}{1+R}$$

\textbf{修正的本质是"自我包含"}：分子加 1 相当于把"观测到的这一次"也算作一次置换结果。

\textbf{为什么需要修正}：

当 $R=99$ 次置换中，只有 0 次超过观测值时：
$$\hat{p}_{frt} = \frac{0}{99} = 0$$

这就错了！因为观测到的这一次（自身）必然是 $M$ 种可能之一，p 值至少应该是 $1/M$，而不是 0。

加了 1 在分子和分母：
$$\tilde{p}_{frt} = \frac{1}{100}$$

这保证了：
\begin{enumerate}
  \item p 值不会为 0（分子至少是 1）
  \item 在任何有限的 $R$ 下都满足有限样本有效性：$\mathbb{P}(p \leq u) \leq u$
  \item 当 $R \to \infty$ 时，$\tilde p_{frt} \to \hat p_{frt}$
\end{enumerate}

\subsection{为什么叫"有限样本精确"？}\label{sec:qa-finite-sample-exact}

\textbf{问}：FRT 的 p 值为什么被称为"有限样本精确"？

\textbf{答}：关键在于 \cref{eq:p-value-valid} 给出的不等式：
$$\mathbb{P}(p_{frt} \leq u) \leq u \quad \text{for all } u \in [0,1]$$

这叫做\textbf{有限样本有效性}（finite-sample validity）。意思是：无论样本量多小、数据分布如何，$p_{frt}$ 的分布永远不会偏离均匀分布太多。

对比传统 t 检验：它需要大样本下才近似有效（渐近性质），小样本时可能失效。FRT 的精确性只依赖于随机化机制，不依赖于任何渐近假设。

\subsection{Fisher 方法 vs 传统方法}\label{sec:qa-fisher-vs-classical}

\textbf{问}：Fisher 的思路和传统统计推断有什么本质区别？

\textbf{答}：

\begin{itemize}
  \item \textbf{传统方法问}：``数据有多极端？''——依赖数据分布假设
  \item \textbf{Fisher 方法问}：``如果随机化，会产生多极端的数据？''——只依赖随机化机制
\end{itemize}

Fisher 方法的哲学：在 sharp null（无因果效应）假设下，潜在结果完全已知。观察到的差异完全来自随机分配。我们可以枚举所有可能的置换，计算每个置换产生的统计量。传统方法则依赖于数据的原始分布假设（如正态性），而 FRT 给经典 t 检验提供了理论justify——不需要正态性假设。

\subsection{经典 t 检验之前没有理论基础吗？}\label{sec:qa-t-test-before-frt}

\textbf{问}：经典 t 检验之前没有理论 justify 吗？一定要 FRT 给出吗？

\textbf{答}：经典 t 检验\textbf{有}理论基础，但 FRT 提供了\textbf{更坚实}的理论基础。

\textbf{经典 t 检验的理论基础}：
\begin{itemize}
  \item \textbf{正态性假设下}（Fisher 原始推导）：如果 $Y_i \sim \text{i.i.d. } \mathcal{N}(\mu, \sigma^2)$，则 t 统计量精确服从 t 分布
  \item \textbf{渐近理论}（后来发展）：大样本下，CLT 保证 t 统计量近似正态分布——即使数据不正态
\end{itemize}

\textbf{FRT 的新贡献}：FRT 并不是说经典 t 检验"没有理论依据"，而是提供了\textbf{另一种理论框架}：

\begin{itemize}
  \item 经典方法：关注"\textbf{数据的分布}"（假设数据来自正态分布）
  \item FRT：关注"\textbf{随机化的机制}"（治疗是如何分配的）
\end{itemize}

\textbf{关键区别}：在随机实验中，我们\textbf{知道}治疗是如何分配的（CRE），所以可以基于随机化机制来计算 p 值——这比假设"数据来自正态分布"更可靠。

\textbf{准确的说法}：FRT 为经典 t 检验在随机实验中的应用提供了\textbf{更直接、更不依赖分布假设}的理论基础。

\subsection{经典 t 检验需要正态性假设吗？}\label{sec:qa-t-test-normality}

\textbf{问}：经典 t 检验需要正态性假设吗？为什么 FRT 说"不需要"？

\textbf{答}：经典 t 检验有两种情况：

\begin{itemize}
  \item \textbf{精确版本}：如果数据来自正态分布的总体，t 统计量的精确抽样分布是 t 分布
  \item \textbf{渐近版本}：在大样本下，即使数据不正态，CLT 保证 t 统计量近似正态分布
\end{itemize}

\textbf{FRT 的贡献}：它证明了在随机实验 + sharp null 下，t 统计量的\textbf{随机化分布}可以直接计算（精确或 Monte Carlo 近似），不依赖任何分布假设。

\textbf{关键区别}：
\begin{itemize}
  \item 传统方法问："如果数据来自正态分布，观察到的差异有多极端？"
  \item FRT 问："如果 treatment 是随机分配的，观察到这种差异的概率有多大？"
\end{itemize}

FRT 的理论基础是有限总体 CLT，它保证\textbf{随机化分布}收敛到正态，而不是数据本身正态。因此在大样本下，即使数据不正态，FRT 给出的 p 值也是有效的。

\textbf{总结}：FRT 并没有说经典 t 检验"不需要"正态性假设，而是说在随机实验框架下，可以用不依赖正态性的方法（FRT）来获得精确的 p 值。

\subsection{什么是潜在结果？}\label{sec:qa-potential-outcomes}

\textbf{问}：在 Fisher 随机化检验框架下，什么是潜在结果？

\textbf{答}：潜在结果（Potential Outcomes）是每个单元在两种 treatment 状态下的可能结果：

\begin{itemize}
  \item $Y_i(1)$：单元 $i$ 如果接受 treatment 的结果
  \item $Y_i(0)$：单元 $i$ 如果接受 control 的结果
\end{itemize}

\textbf{关键洞察}：每个单元只能实际接受一种 treatment，因此我们只能观测到其中一个潜在结果，另一个是"反事实"（counterfactual）——它从未发生，无法被观测。

\textbf{观测结果与潜在结果的关系}：
\[
Y_i^{obs} = Z_i Y_i(1) + (1 - Z_i) Y_i(0)
\]
即：如果 $Z_i=1$（接受 treatment），我们观测到 $Y_i(1)$；如果 $Z_i=0$，我们观测到 $Y_i(0)$。

\textbf{因果推断的根本问题}：我们想估计 $Y_i(1) - Y_i(0)$（单元 $i$ 的因果效应），但只能观测到其中一个值。

\subsection{随机化的两个原则是什么？}\label{sec:qa-randomization-principles}

\textbf{问}：Fisher 随机化的两个原则——可比性和推理基础——是什么意思？

\textbf{原则一：可比性（Comparability）}。随机化保证了 treatment 组和 control 组在平均意义下是可比的。如果没有随机化，治疗分配可能受到选择偏差（selection bias）的影响。例如，如果病人自己选择是否接受治疗，那么接受治疗的群体可能本身就比对照组更健康。随机化通过强制分配机制打破了这种联系，使得两组在所有可观测和不可观测的特质上趋于平衡。

\textbf{原则二：推理基础（Inference Basis）}。随机化提供了推断因果效应的理论基础。在没有随机化的情况下，我们无法区分"因果效应"和"选择偏差"。但在随机实验中，我们知道治疗分配是如何进行的（randomization mechanism），因此可以基于这个已知的分配机制来计算 p 值。具体而言：

\begin{enumerate}
  \item 假设 $H_{0F}$：treatment 对每个人都无效（$Y_i(1) = Y_i(0)$）
  \item 在这个假设下，治疗分配是唯一的随机来源
  \item 枚举所有可能的随机分配（或者 Monte Carlo 近似）
  \item 计算在每种分配下，检验统计量有多极端
\end{enumerate}

\textbf{总结}：可比性解决"选择偏差"——确保组间可比较。推理基础解决"随机变异"——知道观察到的差异有多极端。两者结合，使得因果推断成为可能。

\subsection{什么是 Fisher Randomization Test？}\label{sec:qa-fisher-randomization-test}

\textbf{问}：什么是 Fisher Randomization Test（Fisher 随机化检验）？

\textbf{答}：Fisher Randomization Test (FRT) 是 Ronald Fisher 在 1935 年《Design of Experiments》中提出的统计检验框架。它的核心创新是：不再依赖数据分布假设（如正态性），而是\textbf{仅依赖随机化机制本身}。

\textbf{核心思想}：

\begin{enumerate}
  \item 在 \textbf{sharp null} 假设 $H_{0F}: Y_i(1) = Y_i(0)$（所有单元的治疗效应都为零）下，潜在结果向量 $\mathbf{Y}$ 是完全确定的（固定的）
  \item 唯一的随机来源是治疗分配机制 $\mathbf{Z}$
  \item 在完全随机实验（CRE）中，$\mathbf{Z}$ 的分布是已知的（均匀分布于所有 $\binom{n}{n_1}$ 种可能的分配）
  \item 因此，我们可以枚举所有可能的治疗分配，计算在每种分配下检验统计量的取值
  \item p 值就是在所有可能分配中，观察到的统计量至少与实际观测值一样极端的比例
\end{enumerate}

$\star$ \textbf{Insight}：FRT 的本质是"条件推断"——我们 condition on 固定的潜在结果 $\mathbf{Y}$，只让治疗分配 $\mathbf{Z}$ 有随机性。这与经典统计推断不同：经典方法 condition on 数据，假设数据的分布已知；FRT 则 condition on 潜在结果，利用随机化机制计算精确的 p 值。

\textbf{为什么叫"随机化检验"？}因为它完全基于随机化机制——不假设任何参数分布，不依赖正态性假设，只依赖"治疗是如何随机分配的"这一事实。这使得 FRT 在随机实验中具有"有限样本精确性"（finite-sample exactness）。

\subsection{$\{\mathbf{z}^1, \ldots, \mathbf{z}^M\}$ 的含义}\label{sec:qa-z-set-meaning}

\textbf{问}：在 CRE 中，$\mathbf{Z}$ 在集合 $\{\mathbf{z}^1, \ldots, \mathbf{z}^M\}$ 上是均匀分布的。这句话是什么意思？

\textbf{答}：

\textbf{先理解 $\mathbf{Z}$ 是什么}。$\mathbf{Z} = (Z_1, \ldots, Z_n)$ 是治疗分配向量，其中 $Z_i = 1$ 表示单元 $i$ 接受治疗，$Z_i = 0$ 表示单元 $i$ 接受对照。

\textbf{再理解 $\{\mathbf{z}^1, \ldots, \mathbf{z}^M\}$}。这是所有可能的治疗分配构成的集合。例如当 $n=3, n_1=1$ 时，所有可能的分配有：
$$\mathbf{z}^1 = (1,0,0), \mathbf{z}^2 = (0,1,0), \mathbf{z}^3 = (0,0,1)$$
即 $M = \binom{3}{1} = 3$ 种可能。

\textbf{"均匀分布"的意思}。在 CRE 中，治疗分配是完全随机的。这意味着每一种可能的分配 $\mathbf{z}^m$ 被选中的概率相等：
$$\mathbb{P}(\mathbf{Z} = \mathbf{z}^m) = \frac{1}{M} = \frac{1}{\binom{n}{n_1}}$$

例如当 $n=100, n_1=50$ 时，$M \approx 10^{29}$ 种可能的分配，每一种被选中的概率都完全相同（约 $10^{-29}$）。

\textbf{关键直觉}：在 CRE 下，treatment 组和 control 组的成员身份是随机决定的，而非实验者主观选择。这就是 Fisher 说的"randomization provides a valid basis for inference"——随机化本身保证了推断的有效性。

\subsection{蒙特卡洛公式中的 $\mathbf{Z}$ 是什么？}\label{sec:qa-z-in-monte-carlo}

\textbf{问}：蒙特卡洛公式里面的 $\mathbf{Z}$ 到底是什么意思？他说是一个均匀分布，但我不知道 $\mathbf{Z}$ 是什么意思？

\textbf{答}：

\textbf{为什么需要理解 $\mathbf{Z}$？}在 Fisher 随机化检验中，我们感兴趣的问题是："如果 treatment 真的是随机分配的，观察到的差异有多极端？"要回答这个问题，我们需要知道"随机分配"是如何进行的——而 $\mathbf{Z}$ 正是描述这种分配机制的核心工具。

\textbf{$\mathbf{Z}$ 的定义}。在 $n$ 个单元的实验中，$\mathbf{Z} = (Z_1, Z_2, \ldots, Z_n)$ 是一个长度为 $n$ 的向量，其中：
\begin{itemize}
  \item $Z_i = 1$：单元 $i$ 接受 treatment（治疗组）
  \item $Z_i = 0$：单元 $i$ 接受 control（对照组）
\end{itemize}

例如当 $n=5, n_1=2$ 时，一个可能的分配是 $\mathbf{Z} = (1, 0, 0, 1, 0)$，表示第 1、4 号单元接受治疗，第 2、3、5 号单元接受对照。

\textbf{为什么是"均匀分布"？}在完全随机实验（CRE）中，治疗分配是完全随机的——每个可能的 $\mathbf{Z}$ 被选中的概率相等。这就是"均匀分布"的含义。

具体来说，所有可能的分配有 $M = \binom{n}{n_1}$ 种，每种被选中的概率都是 $1/M$。例如：
\begin{itemize}
  \item $n=3, n_1=1$ 时，$M=3$，三种可能：$(1,0,0)$、$(0,1,0)$、$(0,0,1)$，概率各为 $1/3$
  \item $n=100, n_1=50$ 时，$M \approx 10^{29}$，每种概率约为 $10^{-29}$
\end{itemize}

\textbf{$\mathbf{z}^r$ 是什么？}在 Monte Carlo 近似中，我们无法枚举全部 $M$ 种分配。因此我们进行 $R$ 次随机置换，每次得到一个 $\mathbf{z}^r$。每个 $\mathbf{z}^r$ 都是对真实 $\mathbf{Z}$ 的一次模拟。

$\star$ \textbf{Insight}：理解 $\mathbf{Z}$ 的关键是：它是一个指示函数向量（indicator vector），而不是一个普通的数。它告诉我们"谁在接受治疗，谁在对照"。Monte Carlo 方法通过重复模拟这个随机分配过程，来近似在所有可能分配下的检验统计量分布。

\subsection{什么是潜在结果（Potential Outcomes）？}\label{sec:qa-potential-outcomes-general}

\textbf{问}：什么是因果推断中的"潜在结果"（Potential Outcomes）？

\textbf{答}：潜在结果（Potential Outcomes）是指每个研究单元在**不同处理条件下**可能观测到的所有结果。对于单元 $i$：
\begin{itemize}
  \item $Y_i(1)$：单元 $i$ 接受 treatment 后的结果（如吃药后的康复情况）
  \item $Y_i(0)$：单元 $i$ 接受 control 的结果（如不服药的情况）
\end{itemize}

\textbf{核心问题}：我们只能同时观测到**一个**潜在结果，另一个是反事实（counterfactual）。这被称为"因果推断基本问题"（Fundamental Problem of Causal Inference）。

\subsection{第一基本形式的意义}\label{sec:qa-first-fundamental-form}

\textbf{问}：什么是第一基本形式（First Fundamental Form）？

\textbf{答}：第一基本形式是曲面上用来度量弧长、面积以及角度的工具，本质上是曲面自带的一种"度量结构"——它告诉我们如何在曲面上测量距离和角度。

\subsection{远置信集的构造}\label{sec:qa-far-confidence-set}

\textbf{问}：远置信集（far confidence set）是如何构造的？

\textbf{答}：远置信集是通过在参数空间中搜索满足置信水平的最大区域构造的。具体方法是在约束条件下寻找使目标函数最大化的参数点，从而确定置信范围。

\subsection{ITT 的含义}\label{sec:qa-itt-meaning}

\textbf{问}：什么是 ITT（Intent-to-Treat）？

\textbf{答}：ITT 即意向性治疗分析（Intent-to-Treat），是一种保守的估计方法，无论实际是否依从，都按随机分配的方案进行分析。它估计的是"随机化本身的效应"，而非实际治疗的因果效应。

\subsection{工具变量的直觉}\label{sec:qa-iv-intuition}

\textbf{问}：工具变量（Instrumental Variable）的直觉是什么？

\textbf{答}：工具变量 $Z$ 满足：（1）与 treatment 相关；（2）通过随机分配获得外生性；（3）只通过 treatment 影响结果，不能直接影响结果。它的直觉是：通过随机分配产生的 variation（被称为"准实验 variation"），可以用来估计 treatment 效应，即使存在选择偏差。

\subsection{单调性假设是否可检验}\label{sec:qa-monotonicity-testable}

\textbf{问}：单调性假设（Monotonicity）是否可检验？

\textbf{答}：单调性假设（$Y_i(1) \geq Y_i(0)$ 对所有人成立）通常是不可直接检验的，因为它涉及反事实结果。但在某些特殊情况下（如二元结果、随机实验），可以通过辅助假设或分层分析提供间接证据。

\subsection{随机化假设的含义}\label{sec:qa-randomization-assumption}

\textbf{问}：随机化假设（Randomization Assumption）在工具变量框架下意味着什么？

\textbf{答}：随机化假设是指工具变量 $Z$ 与潜在结果 $(Y_i(0), Y_i(1))$ 和潜在处理 $(D_i(0), D_i(1))$ 是相互独立的，即 $Z \perp (Y_i(0), Y_i(1), D_i(0), D_i(1))$。这确保了工具变量的外生性，排除了一切混杂。

\subsection{弱工具变量问题}\label{sec:qa-weak-iv-problem}

\textbf{问}：什么是弱工具变量问题（Weak IV Problem）？

\textbf{答}：弱工具变量是指与 treatment 相关性很弱的工具变量（$F$ 统计量较小）。使用弱工具变量会导致：偏差增大、置信区间扩张、有限样本下分布偏离标准分布。需要检查 $F$ 统计量是否超过临界值（如 Staiger-Stock 规则中的 10）。

\subsection{为什么是局部平均处理效应}\label{sec:qa-why-local}

\textbf{问}：工具变量方法估计的为什么是"局部"平均处理效应（LATE）而非总体 ATE？

\textbf{答}：因为工具变量利用的是"受工具影响的 Compliers"的 variation。在单调性假设下，只有 Compliers（$D_i(1) > D_i(0)$）对工具变量的效应有贡献，而 Defiers 和 Always-takers 被排除。因此估计量只识别了 Compliers 群体的 ATE，即 LATE。
