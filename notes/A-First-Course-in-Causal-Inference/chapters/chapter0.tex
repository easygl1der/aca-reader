\chapter*{引言：文献概述}\label{chap:introduction}
\addcontentsline{toc}{chapter}{引言：文献概述}

本学习资料旨在系统研究因果推断（Causal Inference）的基础理论与方法。因果推断是现代统计学和计量经济学最重要的研究领域之一，它关注如何从观测数据或实验数据中推断出因果关系，而不仅仅是相关关系。

\section{总述}

在科学研究中，"相关并不意味着因果"是一个基本常识。然而，在实际研究中，我们常常需要回答因果性问题：某种治疗是否有效？某个政策是否达到了预期效果？某个变量之间的关联是否具有因果性质？

Rubin（1974）提出的潜在结果框架（Potential Outcomes Framework）为因果推断奠定了理论基础。在该框架下，每个单元在不同处理条件下都有对应的潜在结果，而我们只能观测到其中一个。这种"因果推断基本问题"推动了各种推断方法的发展。

本课程以 Peng Ding 的《A First Course in Causal Inference》为主教材，系统学习：
\begin{itemize}
    \item 完全随机化实验中的因果推断方法
    \item Fisher 随机化检验与 Neyman 重复抽样推断
    \item 分层分析与后分层技术
    \item 观测性研究中的因果推断
    \item 倾向得分、工具变量、回归断点设计等高级主题
\end{itemize}

\section{文献摘要总结}\label{sec:literature-summary}

\subsection{A First Course in Causal Inference}
\begin{enumerate}
    \item \textbf{作者:} Peng Ding（丁鹏）
    \item \textbf{链接:} \url{https://arxiv.org/abs/2305.18793}
    \item \textbf{年份:} 2023
    \item \textbf{篇幅:} 约 420 页
    \item \textbf{核心贡献:}
        \begin{itemize}
            \item 系统整合了 Fisher 精确推断与 Neyman 渐近推断两大框架
            \item 提出了条件随机化实验（CRE）的统一处理方法
            \item 详细讨论了分层、后分层与协变量平衡技术
            \item 涵盖了观测性研究中的因果推断主流方法
        \end{itemize}
    \item \textbf{摘要:} This book provides an introduction to causal inference for students and researchers interested in estimating treatment effects from randomized experiments and observational studies. It unifies the potential outcomes framework with a focus on randomization-based inference, covering topics from basic concepts like the Yule-Simpson paradox to advanced methods including propensity score matching, instrumental variables, and sensitivity analysis. The book emphasizes both finite-sample exact inference (Fisher's approach) and asymptotic inference (Neyman's approach), providing readers with a comprehensive toolkit for causal analysis.
    \item \textbf{关键词:} Causal Inference；Potential Outcomes；Randomization Test；Neyman Inference；Observational Studies；Propensity Score
\end{enumerate}

\section{补充参考资料}

\begin{itemize}
    \item \textbf{Imbens and Rubin (2015):} \textit{Causal Inference for Statistics, Social, and Biomedical Sciences.} Cambridge University Press. — 因果推断的权威教材。
    \item \textbf{Rubin (1974):} ``Estimating Causal Effects of Treatments in Randomized and Non-Randomized Studies.'' \textit{Journal of Educational Psychology.} — 潜在结果框架的奠基性论文。
    \item \textbf{Rosenbaum and Rubin (1983):} ``The Central Role of the Propensity Score in Observational Studies for Causal Effects.'' \textit{Biometrika.} — 倾向得分理论的开创性工作。
    \item \textbf{Angrist and Pischke (2009):} \textit{Mastering `Metrics}.'' Princeton University Press. — 计量经济学因果推断的入门读物。
\end{itemize}

\section{学习路径与前置基础知识}

\textbf{数学基础：}
\begin{itemize}
    \item 概率论：条件概率、条件期望、方差与协方差
    \item 统计学：点估计、置信区间、假设检验
    \item 线性代数：矩阵运算、特征值
\end{itemize}

\textbf{概率不等式：}
\begin{itemize}
    \item Markov 不等式、Chebyshev 不等式
    \item Hoeffding 不等式、Chernoff 界
    \item CLT（中心极限定理）
\end{itemize}

\textbf{推荐学习顺序：}
\begin{enumerate}
    \item 第 1-2 章：基础概念（相关与因果、潜在结果）
    \item 第 3-4 章：完全随机化实验（Fisher 检验与 Neyman 推断）
    \item 第 5 章：分层与后分层
    \item 第 6-8 章：随机化实验的高级话题
    \item 第 9 章：有限总体与超总体的统一框架
    \item 第 10-18 章：观测性研究方法
\end{enumerate}

\section{最终目标}

完成本课程学习后，期望达到以下目标：

\begin{itemize}
    \item \textbf{理论理解：} 深入理解潜在结果框架，掌握 Fisher 精确推断与 Neyman 渐近推断的理论基础与联系。
    \item \textbf{方法掌握：} 熟练运用各种因果推断方法，包括分层、协变量调整、倾向得分匹配、工具变量等。
    \item \textbf{应用能力：} 能够针对实际研究问题设计合适的因果推断策略，正确解读分析结果。
    \item \textbf{批判思维：} 能够识别因果推断中的常见陷阱（如辛普森悖论、选择偏差、混杂因素），并进行敏感性分析。
\end{itemize}
