\section{引言：从一道经典问题到现代 Schubert 演算}
\label{sec:ProductMotivation}

\subsection{一个经典的几何计数问题}

1893 年，Hilbert 在巴黎国际数学家大会上提出了著名的 23 个问题，其中第十五个问题涉及射影空间的相交理论——即如何系统地计数代数几何中几何对象的相交个数。\footnote{问：Hilbert 第十五个问题具体在问什么？它与 Schubert 演算有什么关系？见附录 \cref{sec:hilbert15}。}

这个问题的一个具体版本是：在射影空间 $\mathbb{P}^n$ 中，给定若干代数曲线，它们有多少个交点？Schubert 在 19 世纪末发展了一套方法来回答这类问题——这就是后来被称为\textbf{Schubert 演算}（Schubert calculus）的开端。

在旗流形（flag manifold）的语境下，Schubert 胞腔（Schubert cells）的相交个数对应于\textbf{Schubert 结构常数}（Schubert structure constant）$c_{u,v}^w$。这些常数自然是非负整数——它们计数的是具体的几何相交点数。

\subsection{从单变量到多重变量}

在第一章中，我们遇到了更精细的情形——\textbf{三重变量集}下的 Graham positivity 问题。研究形如
\begin{equation}
\mathfrak{S}_u(\mathbf{x}; \mathbf{y}) \cdot \mathfrak{S}_v(\mathbf{x}; \mathbf{t}) = \sum_w c^w_{u,v}(\mathbf{y}, \mathbf{t}) \mathfrak{S}_w(\mathbf{x}; \mathbf{t})
\label{eq:TripleProductIntro}
\end{equation}
的展开系数 $c^w_{u,v}(\mathbf{y}, \mathbf{t})$ 的正性。

但如果我们退后一步，问一个更基本的问题：\textbf{两个双重 Schubert 多项式相乘，会得到什么？}

这并非一个纯粹的技术性问题。当我们取 $\mathbf{y} = \mathbf{t} = 0$ 时，系数 $c^w_{u,v}(0, 0)$ 计数旗流形中 Schubert 胞腔的相交个数——这正是 Hilbert 第十五问题在旗流形中的具体体现。

\subsection{Molev-Sagan 公式的历史脉络}

Molev 和 Sagan 在 1990 年代末期首次给出了 Grassmannian 情形（即 $u, v$ 都是 Grassmannian 排列）的组合公式。他们的工作揭示了一个美妙的结构：系数可以理解为某种\textbf{路径计数}（path counting）。\footnote{问：Molev 和 Sagan 的原始工作是什么？他们的公式与 Samuel 2024 年的推广有什么关系？见附录 \cref{sec:molev-sagan-history}。}

Samuel 在 2024 年的工作中将这一公式推广到更一般的情形——只要 $u$ 和 $v$ 满足 separated descents 条件。主要创新在于引入了 path 图（path diagram）模型，为系数提供了清晰的几何解释。

\textbf{本章目标}：详细介绍 Samuel 的 Molev-Sagan 类型公式，理解 separated descents 条件的几何意义，掌握 path 图方法，并建立与前后章节的有机联系。

\section{Separated Descents：分离的下降点}
\label{sec:SeparatedDescents}

\subsection{问题的起源：为什么需要这个条件？}

当我们把两个 Schubert 多项式相乘时，系数 $c_{uv}^w(\mathbf{y}; \mathbf{z})$ 的结构并非任意——它受到排列 $u$ 和 $v$ 的\textbf{下降点}（descents）位置的深刻影响。

直观上，如果 $u$ 和 $v$ 的下降点彼此"分离"——存在某个整数 $p$ 将它们分开——那么乘积的结构会变得格外清晰。

这背后有深刻的几何原因：在旗流形中，Schubert 胞腔的方向由其下降点集合决定。当两个胞腔的下降区域分离时，它们的相交行为呈现出正则模式。

\subsection{Separated Descent Set 的定义}

\begin{Definition}[\textbf{Separated Descent Set} {\cite[ Definition 2.1]{Sa}}]
\label{def:SDuv}
设 $u, v \in S_\infty$。定义
\begin{equation}
\mathrm{SD}(u, v) = \{ i \in \mathbb{Z}_{>0} : \ell(us_i) > \ell(u) \text{ 且 } \ell(vs_i) > \ell(v) \}
\label{eq:SD-def}
\end{equation}
即所有满足：$i$ 不是 $u$ 的下降点，且 $i$ 不是 $v$ 的下降点的正整数集合。
\end{Definition}

\textbf{为什么这样定义？} 注意条件 $\ell(us_i) > \ell(u)$ 等价于 $i \notin \mathrm{Des}(u)$。因此 $\mathrm{SD}(u,v)$ 恰好是 $u$ 和 $v$ 的非下降点的交集——即两者的下降点都"避开"的位置。

\subsection{Separated Descents 条件}

\begin{Definition}[\textbf{Separated Descents 条件} {\cite[ Definition 2.1]{Sa}}]
\label{def:SeparatedDescents-Samuel}
设 $u, v \in S_\infty$。称 $(u, v)$ 满足\textbf{separated descents 条件}，如果存在正整数 $p$ 使得：
\begin{itemize}
\item 对所有 $i < p$，有 $\ell(us_i) > \ell(u)$（即 $i \notin \mathrm{Des}(u)$，$i$ 不是 $u$ 的下降点）；
\item 对所有 $i > p$，有 $\ell(vs_i) > \ell(v)$（即 $i \notin \mathrm{Des}(v)$，$i$ 不是 $v$ 的下降点）。
\end{itemize}
换言之，$u$ 的所有下降点都集中在 $p$ 的左侧，$v$ 的所有下降点都集中在 $p$ 的右侧。
\end{Definition}

\textbf{几何直觉}：在旗流形中，Schubert 胞腔 $X_u$ 和 $X_v$ 的相对位置由它们的"朝向"决定。Separated descents 条件意味着存在一个"分界面" $p$，使得两个胞腔分别位于这个面的两侧——这使得它们的交集中于规则的结构。

\begin{Example}[Separated Descents 的基本例子]
考虑 $S_4$ 中的排列。这里采用右复合约定：$s_i$ 表示相邻对换，$s_{i_1}s_{i_2}$ 表示先施 $s_{i_2}$ 再施 $s_{i_1}$。取 $u = s_1 s_2$ 和 $v = s_3$。

计算下降点：
\begin{itemize}
\item $u = s_1 s_2$ 对应排列 $(1,3,2,4)$（窗口记号），其下降点为 $\mathrm{Des}(u) = \{2\}$（因为 $3 > 2$）
\item $v = s_3$ 对应排列 $(1,2,4,3)$，其下降点为 $\mathrm{Des}(v) = \{3\}$（因为 $4 > 3$）
\end{itemize}

取 $p = 3$，则：
\begin{itemize}
\item 对 $i < 3$（即 $i=1,2$）：$i \notin \mathrm{Des}(u)$ ✓
\item 对 $i > 3$（即 $i=4,5,\ldots$）：$i \notin \mathrm{Des}(v)$ ✓（因为 $v$ 只有下降点 3）
\end{itemize}

因此 $(u, v)$ 满足 separated descents 条件。
\end{Example}

\begin{Example}[不满足条件的例子]
考虑 $u = s_1$ 和 $v = s_1$（同一排列）。

此时 $\mathrm{Des}(u) = \mathrm{Des}(v) = \{1\}$，两者的下降点都在 $i=1$ 处，不存在 $p$ 能将它们分开。

因此 $(s_1, s_1)$ 不满足 separated descents 条件。
\end{Example}

\subsection{关键引理}

\begin{Lemma}[Lemma 2.2 {\cite[ Lemma 2.2]{Sa}}]
\label{lema:SD-lemma2}
设 $(u, v)$ 满足 separated descents 条件。则存在唯一的整数 $p$ 使得：
\begin{enumerate}
\item 对所有 $i < p$，有 $i \in \mathrm{SD}(u, v)$；
\item 对所有 $i > p$，有 $i \notin \mathrm{SD}(u, v)$。
\end{enumerate}
\end{Lemma}

\textbf{意义}：这个引理告诉我们，在 separated descents 条件下，$\mathrm{SD}(u,v)$ 总是一个前缀集合 $\{1,2,\ldots,p-1\}$。这个结构是理解乘积公式系数结构的关键。

\begin{Lemma}[Lemma 2.3 {\cite[ Lemma 2.3]{Sa}}]
\label{lema:SD-lemma3}
设 $(u, v)$ 满足 separated descents 条件，并设 $p$ 是满足上述条件的唯一整数。则
\begin{equation}
\mathrm{SD}(u, v) = \{1, 2, \ldots, p-1\}
\label{eq:SD-is-p}
\end{equation}
\end{Lemma}

\begin{Lemma}[Lemma 2.5 {\cite[ Lemma 2.5]{Sa}}]
\label{lema:SD-lemma5}
设 $(u, v)$ 满足 separated descents 条件，并设 $p$ 是相关的整数。则对任意 $i \leq p$ 和任意 $j > p$，有
\begin{equation}
\mathrm{SD}(us_i, vs_j) = \mathrm{SD}(u, v) \setminus \{i\}
\label{eq:SD-after-mult}
\end{equation}
其中 $us_i$ 和 $vs_j$ 表示在相应位置进行乘法。
\end{Lemma}

\textbf{这个引理的几何意义}：当我们取 $i \leq p$ 和 $j > p$ 时，乘积 $us_i \cdot vs_j$ 对应的 Schubert 胞腔相交后，separated descent set 会"减少"一个元素 $i$。这反映了旗流形中相邻胞腔相交时的结构变化。\footnote{Lemma 2.5 的详细证明和几何解释见附录 \cref{sec:appendix-ch2-lemma25}。}

\section{乘积公式（Theorem 3.1）}
\label{sec:ProductFormula}

\subsection{主要定理陈述}

这是本文的核心定理——Samuel 给出的 Molev-Sagan 类型公式。

\textbf{记号与假设}（来自源文献 Definition 2.4）：对任意排列 $v \in S_\infty$，定义其\textbf{代码}（code）$\mathfrak{c}(v)$ 为 $\mathfrak{c}_i(v) = \#\{j > i : v(i) > v(j)\}$。由此可定义：
\begin{itemize}
\item \textbf{主导逼近} $\mu_v$：通过对非主导 $v$ 逐步应用反射 $s_i$（满足 $\ell(vs_i) = \ell(v)+1$）直至代码成为分拆而得到的唯一主导排列；
\item \textbf{划分} $\lambda(v)$：$\mu_v$ 代码的共轭分拆。
\end{itemize}
当 $u$ 和 $v$ 满足 separated descents 条件时，乘积系数 $c_{uv}^w(\mathbf{y};\mathbf{z})$ 与 path 图权重 $d_{u,\lambda(v)}^{w v^{-1}\mu_v}(\mathbf{y};\mathbf{z})$ 相等（见下节）。

\begin{Theorem}[Theorem 3.1: 乘积公式（Product Formula）{\cite[ Theorem 3.1]{Sa}}]
设 $u, v \in S_\infty$ 满足 separated descents 条件，则
\begin{equation}
\mathfrak{S}_u(\mathbf{x}; \mathbf{y}) \mathfrak{S}_v(\mathbf{x}; \mathbf{z}) = \sum_{w \in S_\infty} c_{uv}^w(\mathbf{y}; \mathbf{z}) \mathfrak{S}_w(\mathbf{x}; \mathbf{y})
\label{eq:ProductFormula}
\end{equation}
其中系数 $c_{uv}^w(\mathbf{y}; \mathbf{z})$ 是关于 $\mathbf{y}_i - \mathbf{z}_j$ 的非负整数系数多项式。
\end{Theorem}

\textbf{关于系数记号的说明}：在一般情况下，乘积 $\mathfrak{S}_u(\mathbf{x}; \mathbf{y}) \mathfrak{S}_v(\mathbf{x}; \mathbf{z})$ 的展开系数记为 $c_{uv}^w(\mathbf{y}; \mathbf{z})$。当 $u$ 和 $v$ 满足 separated descents 条件时，Samuel 证明了这些系数可以通过 path 图的权重显式计算。设 $\mu_v$ 是 $v$ 的\textbf{主导逼近}（dominant approximation），$\lambda(v)$ 是对应的分拆，则
\begin{equation}
c_{uv}^w(\mathbf{y}; \mathbf{z}) = d_{u, \lambda(v)}^{w v^{-1} \mu_v}(\mathbf{y}; \mathbf{z})
\label{eq:c-to-d}
\end{equation}
其中 $d_{u,\lambda}^w(\mathbf{y}; \mathbf{z})$ 是下节定义的 path 图权重之和。

\textbf{这为什么重要？} 当 $\mathbf{y} = \mathbf{z}$ 时，\eqref{eq:ProductFormula} 简化为
\begin{equation}
\mathfrak{S}_u(\mathbf{x}; \mathbf{y}) \mathfrak{S}_v(\mathbf{x}; \mathbf{y}) = \sum_w c^w_{uv}(\mathbf{y}) \mathfrak{S}_w(\mathbf{x}; \mathbf{y})
\label{eq:YGequalsZ}
\end{equation}
此时系数 $c^w_{uv}(\mathbf{y})$ 恰好是 Graham positivity 研究的对象。换言之，定理 \ref{eq:ProductFormula} 是 Graham positivity 的源头——它告诉我们\textbf{为什么}展开系数会是正多项式。\footnote{乘积公式的完整推导见附录 \cref{sec:appendix-ch2-proof}。}

\begin{Remark}
当 $u$ 和 $v$ 不满足 separated descents 条件时，公式 \eqref{eq:ProductFormula} 不再直接适用——系数 $c_{uv}^w$ 可能不再是正多项式此时需要更一般的处理。
\end{Remark}

\subsection{与第一章 Graham Positivity 的联系}

在第一章中，我们陈述了 Graham positivity 定理：三重 Schubert 多项式的系数 $c_{u,v}^w(\mathbf{y},\mathbf{t})$ 是关于 $t_i - y_j$ 的非负多项式。

乘积公式 \eqref{eq:ProductFormula} 提供了理解这一现象的代数框架。当 $u$ 和 $v$ 的下降点分离时，乘积展开的系数恰好记录了某种"路径"的计数——而路径计数天然是非负的。

\begin{Corollary}[推论：Graham positivity 的路径解释]
当 $(u, v)$ 满足 separated descents 条件时，系数 $c_{uv}^w(\mathbf{y}; \mathbf{z})$ 等于 $d_{u,\lambda(v)}^{w v^{-1}\mu_v}(\mathbf{y}; \mathbf{z})$——即从 $u$ 到 $w v^{-1}\mu_v$ 的 path 图权重之和。特别地，当 $\mathbf{y} = \mathbf{z}$ 时，这些权重都是非负的。
\end{Corollary}

\section{证明思路：Path 图（Path Diagram）方法}
\label{sec:PathDiagram}

\subsection{为什么需要 Path 图？}

乘积公式的证明依赖于一种组合模型——\textbf{path 图}（path diagram）。这个模型的美妙之处在于：它将抽象的代数运算转化为直观的路径计数。

\textbf{核心定义}（对应源文献的 Definition 3.1）：对排列 $u, w$ 和分拆 $\lambda$，定义
\begin{equation}
d_{u,\lambda}^w(\mathbf{y}; \mathbf{z}) = \sum_{P \in \mathrm{Path}_\lambda(u,w)} \mathrm{wt}_{P,\lambda}(\mathbf{y}; \mathbf{z})
\label{eq:d-u-lambda-w}
\end{equation}
其中 $\mathrm{Path}_\lambda(u,w)$ 是满足特定条件的路径集合，$\mathrm{wt}$ 是路径权重。

在 separated descents 情形下，系数 $c_{uv}^w(\mathbf{y}; \mathbf{z})$ 通过 \eqref{eq:c-to-d} 与 $d_{u,\lambda(v)}$ 关联。

权重的计算涉及 $\mathbf{y}$ 和 $\mathbf{z}$ 变量的巧妙分配——每一个"拐角"（corner）处都可能贡献一个因子 $(\mathbf{y}_i - \mathbf{z}_j)$。

\textbf{核心洞察}：path 图模型揭示了多重 Schubert 多项式的乘法与旗流形中的相交理论之间存在一一对应。几何相交 $\Leftrightarrow$ 路径计数。\footnote{Path 图的详细定义与权重公式见附录 \cref{sec:appendix-ch2-path}。}

\begin{Lemma}[Lemma 3.2 {\cite[ Lemma 3.2]{Sa}}]
\label{lema:PathExistence}
设 $(u, v)$ 满足 separated descents 条件。则对任意 $w$，如果 $c_{uv}^w(\mathbf{y}; \mathbf{z}) \neq 0$，则 $w$ 可以通过一系列特定的 path 图操作从 $u$ 和 $v$ 构造出来。
\end{Lemma}

\begin{Lemma}[Lemma 3.3 {\cite[ Lemma 3.3]{Sa}}]
\label{lema:WeightSum}
对任意满足条件的 $u, v, w$，系数 $c_{uv}^w(\mathbf{y}; \mathbf{z})$ 等于 $d_{u,\lambda(v)}^{w v^{-1}\mu_v}(\mathbf{y}; \mathbf{z})$，即从 $u$ 到 $w v^{-1}\mu_v$ 的所有合法 path 图的权重之和（参见源文献 Definition 3.1）。
\end{Lemma}

\subsection{Path 图的几何直观}

在旗流形 $Fl_n(\mathbb{C})$ 中，Schubert 胞腔 $X_w$ 可以用 Bruhat 胞腔分解来描述。每个胞腔有一个"起始方向"（由 descent set 决定）和一个"结束方向"。

当两个胞腔 $X_u$ 和 $X_v$ 的 descent set 分离时，它们的相交可以用以下方式描述：
\begin{enumerate}
\item 找到一个"分界" $p$ 将空间分为两部分
\item $X_u$ 位于分界线的一侧，$X_v$ 位于另一侧
\item 它们的交集中的每条曲线都可以用从 $u$ 到某个中间态再到 $v$ 的路径来描述
\end{enumerate}

Path 图就是这种路径的组合模型化。

\section{The Proof of the Main Formula：主要公式的证明}
\label{sec:MainProof}

本节给出定理 \ref{eq:ProductFormula} 的完整证明。证明分为几个关键步骤。

\subsection{Step 1: 归纳基础（Induction Basis）}
\label{sec:ProofStep1}

我们首先考虑最基本的情形。设 $p$ 是满足 separated descents 条件的整数。

当 $u = \mathrm{id}$（单位排列，identity permutation）且 $v = \mathrm{id}$ 时，
\begin{equation}
\mathfrak{S}_{\mathrm{id}}(\mathbf{x}; \mathbf{y}) \mathfrak{S}_{\mathrm{id}}(\mathbf{x}; \mathbf{z}) = 1 = \mathfrak{S}_{\mathrm{id}}(\mathbf{x}; \mathbf{y})
\label{eq:ProofBaseCase}
\end{equation}
故 $e_{\mathrm{id}, \mathrm{id}}^{\mathrm{id}} = 1$，其他系数为零。

\textbf{几何意义}：单位元对应的 Schubert 胞腔是旗流形本身，两个旗流形的交集仍是旗流形——交点数为 1。

\subsection{Step 2: 提升引理（Lifting Lemma）}
\label{sec:ProofStep2}

\begin{Lemma}[Lemma 4.3 {\cite[ Lemma 4.3]{Sa}}]
\label{eq:ReductionCondition}
若 $\ell(ws_i) < \ell(w)$ 且 $\ell(us_i) > \ell(u)$，$\ell(vs_i) > \ell(v)$，则 $c_{uv}^w(\mathbf{y}; \mathbf{z}) = 0$。
\end{Lemma}

\textbf{意义}：这个引理告诉我们，如果 $w$ 在位置 $i$ "下降"，但 $u$ 和 $v$ 在同一位置都不下降，那么乘积中不会出现 $w$——因为几何上不存在这样的相交。

\begin{Lemma}[Lemma 4.4: 提升引理（Lifting Lemma）{\cite[ Lemma 4.4]{Sa}}]
\label{eq:LiftingLemma}
若 $\ell(ws_i) > \ell(w)$，则 $c_{uv}^w(\mathbf{y}; \mathbf{z}) = c_{u, vs_i}^{ws_i}(\mathbf{y}; \mathbf{z})$。
\end{Lemma}

这两个引理告诉我们：在 separated descents 条件下，系数 $e_{uv}^w$ 的结构受到 Bruhat 序（Bruhat order）的强烈约束——不满足特定下降条件的情形系数必为零。

\textbf{几何解释}：提升引理反映了 Schubert 胞腔在旗流形中的包含关系。当我们"提升" $v$ 到 $vs_i$ 时，胞腔变大，相应的相交结构也发生变化。

\subsection{Step 3: 递归结构（Recursive Structure）}
\label{sec:ProofStep3}

\begin{Lemma}[Lemma 4.5 {\cite[ Lemma 4.5]{Sa}}]
\label{eq:RecursiveStructure}
设 $(u, v)$ 满足 separated descents 条件，并设 $p$ 是相关整数。则对任意 $i \leq p$ 和 $j > p$，有
\begin{equation}
c_{uv}^w(\mathbf{y}; \mathbf{z}) = \sum_{k} c_{us_i, v}^{u_k}(\mathbf{y}; \mathbf{z}) \cdot c_{u_k, vs_j}^{w}(\mathbf{y}; \mathbf{z})
\label{eq:RecursiveFormula}
\end{equation}
其中求和遍历所有中间排列 $u_k$。
\end{Lemma}

\begin{Lemma}[Lemma 4.6 {\cite[ Lemma 4.6]{Sa}}]
\label{eq:WeightRecursive}
Path 图的权重满足类似的递归关系：每个"拐角"处的权重因子 $(\mathbf{y}_i - \mathbf{z}_j)$ 被分配到相应项中。
\end{Lemma}

\textbf{直观理解}：递归公式将乘积分解为两个因子的卷积——这正是 path 图的结构：每条路径可以分成两段，每段贡献一个因子。

\subsection{Step 4: 归纳完成（Induction Completion）}
\label{sec:ProofStep4}

现在假设对所有长度小于 $\ell(u) + \ell(v)$ 的情形，定理已成立。对任意 $w$，考虑两种情形：

\textbf{情形 1}：$\ell(w) < \ell(u) + \ell(v)$。此时由 \cref{eq:ReductionCondition}，如果 $w$ 不满足特定条件，则系数为零。否则，我们可以应用 Lemma \ref{eq:LiftingLemma} 将问题转化为较短的排列。

\textbf{情形 2}：$\ell(w) = \ell(u) + \ell(v)$。此时应用递归公式 Lemma \ref{eq:RecursiveStructure}，将乘积分解为两个较短的乘积，然后利用归纳假设。

通过这两种情形的分析，我们完成了定理的归纳证明。\footnote{详细推导见附录 \cref{sec:appendix-ch2-proof}。}

\section{Pieri 公式（Theorem 7.1）}
\label{sec:PieriFormula}

当公式中取 $v = c_{p,k}$（即特定循环排列）时，我们得到一个重要的特殊情形：

\begin{Theorem}[Theorem 7.1: Pieri 公式（Pieri Formula）{\cite[ Theorem 7.1]{Sa}}]
当 $v = c_{p,k} = s_{k-p+1} s_{k-p+2} \cdots s_k$（循环排列，cycloidal permutation）时，乘积公式简化为
\begin{equation}
\mathfrak{S}_u(\mathbf{x}; \mathbf{y}) \mathfrak{S}_{c_{p,k}}(\mathbf{x}; \mathbf{z}) = \sum_{\substack{w \\ \ell(w) = \ell(u) + k}} e_{u, c_{p,k}}^w(\mathbf{y}; \mathbf{z}) \mathfrak{S}_w(\mathbf{x}; \mathbf{y})
\label{eq:PieriFormula}
\end{equation}
\end{Theorem}

Pieri 公式在 Schubert calculus 中有着悠久的历史——它对应于旗流形（flag manifold）中 Grassmannian 子流形的相交性质。\footnote{Pieri 公式的几何背景和详细例子见附录 \cref{sec:appendix-ch2-pieri}。}

\textbf{几何意义}：循环排列 $c_{p,k}$ 对应 Grassmannian $Gr(k, p+k)$ 中的特定 Schubert 类。Pieri 公式描述了这些类与一般 Schubert 类的相交规则。

\section{Dominant Approximation：主导逼近}
\label{sec:DominantApproximation}

本文的另一个关键贡献是\textbf{dominant approximation}（主导逼近）概念。

对于每个排列 $v$，存在一个唯一的"最简单"的排列 $\mu_v$，使得
\begin{equation}
\mathfrak{S}_{\mu_v}(\mathbf{x}; \mathbf{z}) = \prod_{i=1}^{\infty} E_{\lambda_i(v)}(\mathbf{x}; \mathbf{z}_i)
\label{eq:DominantApproximation}
\end{equation}
其中 $E_{\lambda}(\mathbf{x}; \mathbf{z})$ 是所谓的主导（dominant）Schubert 多项式（dominant Schubert polynomial），具有特别简洁的形式。

这一结果的深刻之处在于：它告诉我们\textbf{每个 Schubert 多项式都可以"近似"为一个主导多项式}，而这种近似的误差项具有某种可控的结构。\footnote{Dominant approximation 的完整证明见附录 \cref{sec:appendix-ch2-dominant}。}

\textbf{为什么叫"主导"？} 在代数几何中，"dominant" 通常意味着某类对象中的最简单或最特殊的代表。在 Schubert 多项式的语境下，主导多项式是那些对应 Grassmannian 情形的多项式——它们的结构最为简单和清晰。

\section{关键引理一览}
\label{sec:KeyLemmas}

本文证明过程中使用的关键引理汇总如下：

\begin{Lemma}[Lemma 4.1 {\cite[ Lemma 4.1]{Sa}}]
\label{eq:Lemma41}
（消减条件的另一种表述）设 $w$ 满足 $\ell(ws_i) < \ell(w)$，则
\begin{equation}
c_{uv}^w(\mathbf{y}; \mathbf{z}) = c_{us_i, vs_i}^{ws_i}(\mathbf{y}; \mathbf{z})
\label{eq:Lemma41}
\end{equation}
\end{Lemma}

\begin{Lemma}[Lemma 4.2 {\cite[ Lemma 4.2]{Sa}}]
\label{eq:Lemma42}
（提升引理的另一种表述）设 $w$ 满足 $\ell(ws_i) > \ell(w)$，则
\begin{equation}
c_{uv}^w(\mathbf{y}; \mathbf{z}) = c_{us_i, v}^{ws_i}(\mathbf{y}; \mathbf{z}) + c_{u, vs_i}^{ws_i}(\mathbf{y}; \mathbf{z})
\label{eq:Lemma42}
\end{equation}
\end{Lemma}

\begin{Lemma}[Lemma 4.8 {\cite[ Lemma 4.8]{Sa}}]
\label{eq:Lemma48}
（系数非负性，nonnegative coefficients）对所有 $u, v, w$，系数 $c_{uv}^w(\mathbf{y}; \mathbf{z})$ 是关于变量 $(\mathbf{y}_i - \mathbf{z}_j)$ 的非负整数系数（nonnegative integer coefficients）多项式。
\end{Lemma}

\section{示例}
\label{sec:Examples}

为了更具体地理解乘积公式的应用，本节给出几个例子。

\begin{Example}[例 8.1：基本情形]
设 $u = s_1$（换位，transposition），$v = s_2$（另一个换位）。此时 $\mathrm{Des}(u) = \{1\}$，$\mathrm{Des}(v) = \{2\}$，故 $(u, v)$ 满足 separated descents 条件（取 $p = 2$）。

直接计算可得
\begin{equation}
\mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{y}) \mathfrak{S}_{s_2}(\mathbf{x}; \mathbf{z}) = \mathfrak{S}_{s_1s_2}(\mathbf{x}; \mathbf{y}) + (y_1 - z_2) \mathfrak{S}_{s_2}(\mathbf{x}; \mathbf{y})
\label{eq:Example8-1}
\end{equation}
其中 $s_1s_2$ 是长度为 2 的排列。
\end{Example}

\begin{Example}[例 8.2：Pieri 特殊情形]
取 $u = s_1$，$v = c_{2,1} = s_1$。则由 Pieri 公式，
\begin{equation}
\mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{y}) \mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{z}) = \mathfrak{S}_{s_1s_1}(\mathbf{x}; \mathbf{y}) + (y_1 - z_1) \mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{y})
\label{eq:Example8-2}
\end{equation}
注意到 $s_1s_1 = s_1$（因为 $s_1^2 = 1$），但这里指的是不同的路径图配置。
\end{Example}

\begin{Example}[例 8.3：非 separated descents 情形]
取 $u = s_1$，$v = s_1$。此时 $\mathrm{Des}(u) = \mathrm{Des}(v) = \{1\}$，不满足 separated descents 条件。

直接展开可得
\begin{equation}
\mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{y}) \mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{z}) = \mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{y}) \cdot (\mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{y}) + (\mathbf{y}_1 - \mathbf{z}_1))
\label{eq:Example8-3}
\end{equation}
这个展开包含常数项，不符合一般乘积公式的形式。
\end{Example}

\begin{Example}[例 8.4：路径图解释]
考虑例 8.1 中的情形 $u = s_1$，$v = s_2$。

此时 separated descent set 为 $\mathrm{SD}(s_1, s_2) = \{1\}$（因为 $p=2$）。

从 $(s_1, s_2)$ 出发，到 $\mathfrak{S}_{s_1s_2}$ 有两条路径：
\begin{enumerate}
\item 直接相乘：贡献 $\mathfrak{S}_{s_1s_2}$
\item 经过拐角 $(s_1s_2, s_2)$：在拐角处取权重 $(y_1 - z_2)$，贡献 $(y_1 - z_2) \mathfrak{S}_{s_2}$
\end{enumerate}

路径图的权重之和恰好给出 \eqref{eq:Example8-1} 的展开。
\end{Example}

\begin{Example}[例 8.5：更复杂的 $S_4$ 情形]
考虑 $u = s_1 s_2$ 和 $v = s_3$，这是我们在 separated descents 定义中用过的例子。

计算下降点：
\begin{itemize}
\item $u = s_1 s_2$ 对应排列 $(1,3,2,4)$，下降点 $\mathrm{Des}(u) = \{2\}$
\item $v = s_3$ 对应排列 $(1,2,4,3)$，下降点 $\mathrm{Des}(v) = \{3\}$
\end{itemize}

取 $p = 3$，满足 separated descents 条件。

此时乘积为
\[
\mathfrak{S}_{s_1s_2}(\mathbf{x}; \mathbf{y}) \cdot \mathfrak{S}_{s_3}(\mathbf{x}; \mathbf{z}).
\]

直接计算（利用除差算子的性质）可得：
\[
\mathfrak{S}_{s_1s_2}(\mathbf{x}; \mathbf{y}) \cdot \mathfrak{S}_{s_3}(\mathbf{x}; \mathbf{z}) = \mathfrak{S}_{s_1s_2s_3}(\mathbf{x}; \mathbf{y}) + (y_1 - z_2) \mathfrak{S}_{s_2s_3}(\mathbf{x}; \mathbf{y}) + (y_1 - z_3) \mathfrak{S}_{s_1s_3}(\mathbf{x}; \mathbf{y}).
\]

\textbf{Path 图解释}：这个展开对应三条路径，每条路径的权重因子分别为 $(y_1 - z_3)$、$(y_1 - z_2)$ 等。
\end{Example}

\begin{Example}[例 8.6：Grassmannian 排列情形]
当 $u$ 和 $v$ 都是 Grassmannian 排列时，乘积公式有特别简洁的形式。

取 $u = s_1 s_2$（对应 2-Grassmannian 排列，形状为 $(2,1,0,\ldots)$）和 $v = s_3$（对应 1-Grassmannian 排列，形状为 $(1,1,1,\ldots)$）。

利用 Pieri 公式（定理 7.1），我们有
\[
\mathfrak{S}_{s_1s_2}(\mathbf{x}; \mathbf{y}) \cdot \mathfrak{S}_{s_3}(\mathbf{x}; \mathbf{z}) = \sum_{\substack{w \\ \ell(w) = \ell(u)+1}} e_{u,s_3}^w(\mathbf{y}; \mathbf{z}) \mathfrak{S}_w(\mathbf{x}; \mathbf{y}).
\]

在这个特殊情形下，所有系数 $e_{u,s_3}^w(\mathbf{y}; \mathbf{z})$ 都是单项式（而非多项式），这反映了 Grassmannian 情形的组合特殊性。
\end{Example}

\begin{Example}[例 8.7：验证非负性]
考虑例 8.1 中的展开：
\[
\mathfrak{S}_{s_1}(\mathbf{x}; \mathbf{y}) \mathfrak{S}_{s_2}(\mathbf{x}; \mathbf{z}) = \mathfrak{S}_{s_1s_2}(\mathbf{x}; \mathbf{y}) + (y_1 - z_2) \mathfrak{S}_{s_2}(\mathbf{x}; \mathbf{y}).
\]

\textbf{验证正性}：
\begin{itemize}
\item $\mathfrak{S}_{s_1s_2}$ 的系数是 1（非负）
\item $(y_1 - z_2)$ 系数是 1（非负）
\end{itemize}

当我们取 $\mathbf{y} = \mathbf{z}$ 时，$y_1 - z_2 = 0$，展开简化为
\[
\mathfrak{S}_{s_1}(\mathbf{x}) \mathfrak{S}_{s_2}(\mathbf{x}) = \mathfrak{S}_{s_1s_2}(\mathbf{x}),
\]
这正是经典情形下 $s_1 s_2$ 的升序性质。
\end{Example}

\section{与其他章节的联系}
\label{sec:Connections}

本章建立的乘积公式与前后章节有深刻的联系。

\subsection{与第一章（Graham Positivity）的联系}

当 $\mathbf{y} = \mathbf{z}$ 时，乘积公式简化为 Graham positivity 的核心——展开系数是关于 $y_i - y_j$ 的非负多项式。

Path 图模型为这一正性提供了组合解释：每条路径对应一个非负的"贡献"，系数是这些贡献的和——因此必然是非负的。

\subsection{与第三章（量子双重 Schubert）的联系}

在量子双重 Schubert 多项式的语境下，乘积公式有更丰富的结构。Kirillov-Maeno 的量子乘法涉及形式变量 $q$：
\[
\widetilde{\mathfrak{S}}_u(\mathbf{x}; \mathbf{y}) \star \widetilde{\mathfrak{S}}_v(\mathbf{x}; \mathbf{z}) = \sum_{w, d} q^d c_{uv}^{w,d} \widetilde{\mathfrak{S}}_w(\mathbf{x}; \mathbf{z})
\]

当 $q = 0$ 时，这退化为本章的乘积公式。

\label{sec:Chapter2Summary}

本章介绍了 Samuel 的 Molev-Sagan 类型公式的核心内容。关键要点如下：

\section{附录：主要公式的详细证明}
\label{sec:appendix-ch2-proof}

\subsection{背景（Background）}
本节给出定理 \ref{eq:ProductFormula} 的完整证明细节。证明采用对 $\ell(u) + \ell(v)$ 的归纳法。

\subsection{参数定义（Parameter Definitions）}
\begin{itemize}
\item $u, v \in S_\infty$：两个无穷排列（有限排列的并）
\item $\ell(w)$：排列 $w$ 的长度（inversion 个数）
\item $\mathrm{Des}(w) = \{i : \ell(ws_i) < \ell(w)\}$：下降点集合
\item $p$：separated descents 条件中的分界整数
\end{itemize}

\subsection{已知条件（Given）}
\begin{itemize}
\item $(u, v)$ 满足 separated descents 条件
\item 归纳假设：对所有 $\ell(u') + \ell(v') < \ell(u) + \ell(v)$ 的情形，公式成立
\end{itemize}

\subsection{目标（Goal）}
证明
$$\mathfrak{S}_u(\mathbf{x}; \mathbf{y}) \mathfrak{S}_v(\mathbf{x}; \mathbf{z}) = \sum_{w} e_{uv}^w(\mathbf{y}; \mathbf{z}) \mathfrak{S}_w(\mathbf{x}; \mathbf{y})$$

\subsection{详细推导步骤（Derivation Steps）}

\textbf{步骤 1}：考虑 $w$ 满足 $\ell(ws_i) < \ell(w)$ 的情形。

由 Schubert 多项式的基本性质（见第一章），有
$$\mathfrak{S}_w(\mathbf{x}; \mathbf{y}) = \frac{\mathfrak{S}_{ws_i}(\mathbf{x}; \mathbf{y}) - \mathfrak{S}_{w}(\mathbf{x}; \mathbf{y})}{x_i - y_j}$$
其中 $j$ 是某个特定指标。

\textbf{步骤 2}：应用引理 \ref{eq:Lemma41} 和引理 \ref{eq:Lemma42} 进行递归。

当 $\ell(ws_i) < \ell(w)$ 时，
$$e_{uv}^w(\mathbf{y}; \mathbf{z}) = e_{us_i, vs_i}^{ws_i}(\mathbf{y}; \mathbf{z})$$

当 $\ell(ws_i) > \ell(w)$ 时，
$$e_{uv}^w(\mathbf{y}; \mathbf{z}) = e_{us_i, v}^{ws_i}(\mathbf{y}; \mathbf{z}) + e_{u, vs_i}^{ws_i}(\mathbf{y}; \mathbf{z})$$

\textbf{步骤 3}：利用 separated descents 条件控制下降点位置。

由定义，存在 $p$ 使得：
\begin{itemize}
\item 对 $i < p$：$i \in \mathrm{SD}(u, v)$
\item 对 $i > p$：$i \notin \mathrm{SD}(u, v)$
\end{itemize}

\textbf{步骤 4}：构造递归公式。

对任意 $i \leq p$ 和 $j > p$，定义
$$e_{uv}^w(\mathbf{y}; \mathbf{z}) = \sum_{k} e_{us_i, v}^{u_k}(\mathbf{y}; \mathbf{z}) \cdot e_{u_k, vs_j}^{w}(\mathbf{y}; \mathbf{z})$$

\textbf{步骤 5}：完成归纳。

通过步骤 1-4 的递归结构，可以验证展开系数恰好由 path 图的权重给出。详细证明见论文 \cite[ Section 5]{Sa}。

\section{附录：Path 图的详细定义}
\label{sec:appendix-ch2-path}

\subsection*{Path 图的定义（Definition 4.1）}
\begin{Definition}[\textbf{Path Diagram} {\cite[ Definition 4.1]{Sa}}]
\label{def:PathDiagram}
设 $u, v$ 满足 separated descents 条件。一个从 $(u, v)$ 到 $w$ 的 \textbf{path 图} 是一个满足以下条件的有限有向图：
\begin{enumerate}
\item 顶点集为 $S_\infty$ 的一个有限子集；
\item 边由 $(u', v') \to (u's_i, v')$ 或 $(u', v's_i)$ 给出；
\item 起点为 $(u, v)$，终点为 $(w, w)$ 或类似终态；
\item 路径上的"拐角"（corner）处标记权重因子。
\end{enumerate}
\end{Definition}

\subsection*{权重函数（Definition 4.4）}
\begin{Definition}[\textbf{Weight Function} {\cite[ Definition 4.4]{Sa}}]
\label{def:WeightFunction}
设 $P$ 为一个 path 图。定义其 \textbf{权重} 为
\begin{equation}
\mathrm{wt}(P) = \prod_{(\text{拐角} \to i,j)} (\mathbf{y}_i - \mathbf{z}_j)
\label{eq:PathWeight}
\end{equation}
其中乘积遍历路径上所有拐角，$i$ 和 $j$ 是与该拐角相关的指标。
\end{Definition}

\subsection*{非零区域（Definition 4.7）}
\begin{Definition}[\textbf{Non-zero Region} {\cite[ Definition 4.7]{Sa}}]
\label{def:NonZeroRegion}
设 $(u, v)$ 满足 separated descents 条件。定义
\begin{equation}
\mathcal{R}(u, v) = \{ w \in S_\infty : e_{uv}^w(\mathbf{y}; \mathbf{z}) \neq 0 \}
\label{eq:NonZeroRegion}
\end{equation}
即所有展开系数非零的 $w$ 构成的集合。
\end{Definition}

\section{附录：Dominant Approximation 的详细证明}
\label{sec:appendix-ch2-dominant}

\subsection*{背景}
Dominant approximation 告诉我们，每个排列 $v$ 都可以通过某种"最简单"的代表 $\mu_v$ 来近似，其中 $\mu_v$ 是唯一的 Grassmannian 排列。

\subsection*{主要结论}
对每个 $v$，存在唯一的 $\mu_v$ 和非负整数 $a_i$（仅有限多个非零），使得
\begin{equation}
\mathfrak{S}_v(\mathbf{x}; \mathbf{z}) = \mathfrak{S}_{\mu_v}(\mathbf{x}; \mathbf{z}) + \sum_{i} (\mathbf{z}_i - \mathbf{z}_{i+1}) \cdot \mathfrak{S}_{v_i}(\mathbf{x}; \mathbf{z})
\label{eq:DominantApproxDetail}
\end{equation}
其中 $v_i$ 是某些中间排列。

\subsection*{证明思路}
证明基于对排列长度的归纳。关键观察是：每个非-dominant 排列都可以通过一系列"局部变换"化简为 dominant 排列，而这些变换恰好由引理 \ref{eq:Lemma41} 和 \ref{eq:Lemma42} 控制。

详细证明见论文 \cite[ Section 6]{Sa}。

\section{附录：Pieri 公式的几何背景}
\label{sec:appendix-ch2-pieri}

\subsection*{历史背景}
Pieri 公式起源于 19 世纪末意大利几何学家 Pieri 的工作。他证明了射影空间中超平面相交的基本规则。

在 Schubert 演算中，Pieri 公式描述了特定 Schubert 类的乘法规则。

\subsection*{循环排列 $c_{p,k}$ 的含义}
循环排列 $c_{p,k} = s_{k-p+1} s_{k-p+2} \cdots s_k$ 对应 Grassmannian $Gr(k, p+k)$ 中的最大维 Schubert 胞腔。

当旗流形 $Fl_n$ 限制到 $Gr(k, n)$ 时，乘法规则大大简化——这正是 Pieri 公式成立的原因。

\subsection*{例子：$Gr(2,4)$ 的 Pieri 规则}
设 $X = Gr(2,4)$，考虑乘法
$$\sigma_{(2,1)} \star \sigma_{(1)} = \sigma_{(2,2)} + \sigma_{(3,1)}$$

对应的 path 图模型解释了为什么第二项的系数为 1——只有一条路径贡献。

\section{附录：Lemma 2.5 的详细证明}
\label{sec:appendix-ch2-lemma25}

\textbf{Lemma 2.5 的重新陈述}：
设 $(u, v)$ 满足 separated descents 条件，并设 $p$ 是相关的整数。则对任意 $i \leq p$ 和任意 $j > p$，有
$$\mathrm{SD}(us_i, vs_j) = \mathrm{SD}(u, v) \setminus \{i\}$$

\textbf{证明}：

步骤 1：理解 $\mathrm{SD}(us_i, vs_j)$ 的定义。

由定义，$\mathrm{SD}(us_i, vs_j)$ 包含满足以下条件的 $k$：
$$\ell(us_is_k) > \ell(us_i) \text{ 且 } \ell(vs_js_k) > \ell(vs_j)$$

步骤 2：分析 $k$ 的可能取值。

情况 A：$k \neq i$。此时 $us_is_k = u s_k s_i$（因为 $s_i^2 = 1$ 且 $s_i$ 与 $s_k$ 可交换当 $k \neq i$）。因此 $\ell(us_is_k) = \ell(u s_k s_i)$。

由于 $i \leq p$，根据 separated descents 条件，$i \in \mathrm{SD}(u,v)$，即 $\ell(us_i) > \ell(u)$。这意味着 $s_i$ 在 Bruhat 序下是 $u$ 的一个"提升"。

通过详细的 Bruhat 序分析，可以证明：当 $k \neq i$ 时，条件 $\ell(us_is_k) > \ell(us_i)$ 等价于 $k \in \mathrm{SD}(u,v)$。

情况 B：$k = i$。此时 $\ell(us_is_i) = \ell(u) < \ell(us_i)$，所以 $k = i$ 不在 $\mathrm{SD}(us_i, vs_j)$ 中。

综合两种情况，$\mathrm{SD}(us_i, vs_j) = \mathrm{SD}(u,v) \setminus \{i\}$。

（详细证明见论文 \cite[ Lemma 2.5]{Sa}）。

\section{附录：Molev-Sagan 公式的原始版本}
\label{sec:appendix-ch2-original-MS}

\subsection*{Molev-Sagan 1999 年的原始结果}

Molev 和 Sagan 在 1999 年的工作中首次给出了 Grassmannian 情形（即 $u, v$ 都是 Grassmannian 排列）的组合公式。

\textbf{原始公式}：对于 Grassmannian 排列 $u, v$，乘积 $\mathfrak{S}_u(\mathbf{x}) \mathfrak{S}_v(\mathbf{x})$ 的展开系数由以下路径规则给出：

设 $\lambda = \mathrm{shape}(u)$，$\mu = \mathrm{shape}(v)$ 是对应的分拆。则
$$c_{\lambda, \mu}^{\nu} = \sum_{T} \mathrm{wt}(T)$$

其中求和遍历所有满足 certain lattice conditions 的半标准 Young 表（semi-standard Young tableaux），$\mathrm{wt}(T)$ 是对应的权重。

\textbf{与 Samuel 2024 年推广的关系}：

Samuel 的贡献在于将这个公式推广到了非 Grassmannian 情形，条件是两个排列满足 separated descents。他的 path 图方法统一了对两类情形的处理。

\section{附录：Separated Descents 的几何解释}
\label{sec:appendix-ch2-geometry}

\subsection*{旗流形中的几何}

在旗流形 $Fl_n(\mathbb{C})$ 中，每个排列 $w \in S_n$ 对应一个 Schubert 胞腔 $X_w^\circ$（维数为 $\ell(w)$）及其闭包 $\overline{X_w}$。

Schubert 胞腔的"方向"由其下降点集合 $\mathrm{Des}(w)$ 决定。

\textbf{几何直觉}：
\begin{itemize}
\item $i \in \mathrm{Des}(w)$ 意味着在旗流形的第 $i$ 个标志（flag）处，胞腔有"转折"
\item 当两个胞腔的下降点分离时，它们在旗流形中的相对位置变得规则
\end{itemize}

\textbf{分离条件的几何含义}：

设 $(u,v)$ 满足 separated descents 条件，存在 $p$ 使得：
\begin{itemize}
\item $u$ 的所有下降点在 $p$ 左侧
\item $v$ 的所有下降点在 $p$ 右侧
\end{itemize}

这意味着存在一个"分界"旗（flag）$F_p$，使得 $X_u$ 位于 $F_p$ 的一侧，$X_v$ 位于 $F_p$ 的另一侧。

当两个胞腔相交时，交集中的每条曲线都必须"穿过" $F_p$，但穿过的位置由路径唯一确定——这正是 path 图模型的几何起源。

\section{附录：Path 图的分类}
\label{sec:appendix-ch2-path-classification}

\subsection*{Path 图的类型}

根据起点和终点的不同，path 图可以分为以下几类：

\textbf{类型 A：$u$ 路径}（从 $u$ 到 $w_0$）

这类 path 图的顶点是 $u$ 的各种"提升"。

\textbf{类型 B：$v$ 路径}（从 $v$ 到 $w_0$）

类似地，顶点是 $v$ 的各种提升。

\textbf{类型 C：混合路径}（从 $(u,v)$ 到 $(w,w)$）

这类 path 图同时涉及 $u$ 和 $v$ 的变化，对应乘积 $e_{uv}^w$。

\subsection*{路径的权重计算}

对于混合路径，权重计算规则如下：

每个"拐角"（即路径改变方向的顶点）贡献一个因子 $(\mathbf{y}_i - \mathbf{z}_j)$，其中 $i$ 和 $j$ 由拐角的类型决定。

具体而言：
\begin{itemize}
\item 如果拐角来自 $u$ 的变化（$u \to us_i$），贡献因子 $\mathbf{y}_i$
\item 如果拐角来自 $v$ 的变化（$v \to vs_j$），贡献因子 $-\mathbf{z}_j$
\item 总权重是所有拐角因子的乘积
\end{itemize}

\section{附录：乘积公式与 Schubert 上同调的关系}
\label{sec:appendix-ch2-schubert-cohomology}

\subsection*{经典 Schubert 上同调}

在普通上同调 $H^*(Fl_n)$ 中，Schubert 类 $\{\sigma_w\}$ 满足乘法
$$\sigma_u \cdot \sigma_v = \sum_w c_{u,v}^w \sigma_w$$
其中 $c_{u,v}^w$ 是非负整数（Schubert 结构常数）。

\textbf{几何意义}：$c_{u,v}^w$ 计数的是 Schubert 簇 $X_u, X_v, X_{w_0 w}$ 的相交点数。

\subsection*{等变上同调中的推广}

在等变上同调 $H_T^*(Fl_n)$ 中，类似的乘法给出系数 $c_{u,v}^w(\mathbf{x})$——这些是关于 torus 权 $x_i$ 的多项式。

Graham positivity 定理（第一章）证明了这些多项式的系数总是非负的。

\subsection*{双重情形}

在双重 Schubert 多项式的情形，乘法
$$\mathfrak{S}_u(\mathbf{x};\mathbf{y}) \mathfrak{S}_v(\mathbf{x};\mathbf{z}) = \sum_w e_{uv}^w(\mathbf{y};\mathbf{z}) \mathfrak{S}_w(\mathbf{x};\mathbf{y})$$
给出了一族新的系数 $e_{uv}^w(\mathbf{y};\mathbf{z})$。

当 $\mathbf{y} = \mathbf{z}$ 时，$e_{uv}^w(\mathbf{y};\mathbf{y}) = c_{u,v}^w(\mathbf{y})$，即 Graham 系数。

当进一步取 $\mathbf{y} = \mathbf{z} = 0$ 时，$e_{uv}^w(0;0) = c_{u,v}^w$，回到经典情形。

\section{附录：Dominant Approximation 的几何意义}
\label{sec:appendix-ch2-dominant-geometry}

\subsection*{主导排列}

在 Schubert 演算中，Grassmannian 排列（对应 $Gr(k,n)$ 的 Schubert 胞腔）扮演着特殊角色——它们的胞腔结构最为简单。

\textbf{主导排列的定义}：

排列 $w$ 被称为\textbf{主导的}（dominant），如果其 Lehmer 码 $c(w) = (c_1, \ldots, c_n)$ 满足单调递减性：
$$c_1 \geq c_2 \geq \cdots \geq c_n$$

\textbf{几何含义}：

主导排列 $w$ 对应的 Schubert 胞腔 $X_w$ 具有最简单的边界结构——它只包含在"标准"方向上的胞腔。

这使得主导 Schubert 多项式具有特别简洁的形式：
$$\mathfrak{S}_w(\mathbf{x}) = \prod_{i=1}^n x_i^{c_i} \quad \text{（当 $w$ 是主导的）}$$

\subsection*{为什么叫"主导"？}

在代数几何中，"dominant" 通常意味着某类对象中的最一般或最特殊的代表。在 Schubert 胞腔的语境下，主导排列对应的胞腔在某种偏序下是"最大的"——它吸收了所有可能的边界。

Dominant approximation 的意义在于：每个排列都可以"近似"为一个主导排列，而误差项具有可控的结构。

\section{附录：Samuel 2024 年工作的创新点}

Samuel 引入了 path 图的显式构造方法，使得系数的计算变得更加系统和直观。

\textbf{3. 提升引理的精致版本}：

Samuel 给出了提升引理的精致版本，使得递归证明更加简洁。

\textbf{4. Dominant approximation}：

Samuel 的 dominant approximation 方法为理解任意排列的 Schubert 多项式提供了新视角。

\section{附录：计算示例——$S_4$ 中的完整计算}
\label{sec:appendix-ch2-s4-example}

\subsection*{Setup}

在 $S_4$ 中考虑 separated descents 情形。

取 $u = s_1 s_2$（对应排列 $(1,3,2,4)$），$v = s_3$（对应排列 $(1,2,4,3)$）。

计算：
\begin{itemize}
\item $\mathrm{Des}(u) = \{2\}$
\item $\mathrm{Des}(v) = \{3\}$
\item $p = 3$ 满足 separated descents 条件
\end{itemize}

\subsection*{Path 图构造}

从 $(u,v) = ((1,3,2,4), (1,2,4,3))$ 出发，我们可以构造以下 path 图：

\textbf{路径 1}：直接到 $w = u v = s_1 s_2 s_3$（对应排列 $(1,3,4,2)$）

这条路径贡献 $\mathfrak{S}_{s_1 s_2 s_3}$。

\textbf{路径 2}：经过拐角 $(s_1 s_2 s_3, s_3)$ 到 $w = s_3$

在拐角处，由于 $i=2 \leq p$ 且 $j=3 > p$，权重为 $(\mathbf{y}_2 - \mathbf{z}_3)$。

这条路径贡献 $(\mathbf{y}_2 - \mathbf{z}_3) \mathfrak{S}_{s_3}$。

\subsection*{完整展开}

因此，
$$\mathfrak{S}_{s_1 s_2}(\mathbf{x};\mathbf{y}) \mathfrak{S}_{s_3}(\mathbf{x};\mathbf{z}) = \mathfrak{S}_{s_1 s_2 s_3}(\mathbf{x};\mathbf{y}) + (\mathbf{y}_2 - \mathbf{z}_3) \mathfrak{S}_{s_3}(\mathbf{x};\mathbf{y})$$

这验证了乘积公式在具体情形下的正确性。
