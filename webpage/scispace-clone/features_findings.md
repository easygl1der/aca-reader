## 1. Main Product Features

### 1.1 Chat with PDF (Copilot)
The flagship feature - an AI-powered assistant for reading and understanding research papers.

**Key Capabilities:**
- **Ask Questions**: Natural language Q&A about PDF content
- **Multi-language Support**: Generate responses in any language
- **Suggestions Feature**: Auto-generated questions tailored to the paper; "Brainstorm Questions" button for custom questions
- **Navigation Pills**: Quick navigation through different sections of scientific papers
- **Refine Search Scope**:
  - "Only This Paper" - search within current PDF
  - "All Papers" - search across all SciSpace files
  - "My Library" - search within personal library/collections
- **Math & Table Explanation**: Special "sum" icon button to explain tables and mathematical equations
- **Text Highlighting**: Highlight text within PDFs for reference
- **Research Gap Detection**: AI-powered identification of research gaps in a field

**URL:** https://scispace.com/chat-pdf
