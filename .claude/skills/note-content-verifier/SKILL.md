# 笔记内容验证工具

验证笔记中的引理、定理、公式、证明是否与原始论文完全一致，杜绝幻觉和捏造。

## 触发条件

当用户说以下内容时使用此 skill：
- "检查笔记是否和原文一致"
- "验证没有幻觉"
- "检查是否有捏造"
- "对照原文检查"
- "确认定理/引理/证明是否正确"

## 验证范围

### 1. 定理/引理编号验证
- 定理编号是否与原文一致（如论文是 Theorem 2.3，笔记不能写成 Theorem 2.2）
- 引理、推论编号是否正确

### 2. 公式/等式验证
- 检查笔记中的公式与原文是否完全一致
- 特别注意下标、上标、求和范围、上下界
- 检查变量使用是否正确（如 $c^w_{u,v}$ vs $c_{u,v}^w$）

### 3. 证明验证
- 证明是基于原文还是自行编造
- 引用的引理/定理是否在原文存在
- 证明逻辑是否正确

### 4. 引用验证
- cite 引用中的年份、页码、章节号是否正确
- 格式是否规范（如 \cite[ Theorem 1.1]{author}）

## 工作流程

### 步骤 1：定位原文转录文件

首先确定笔记对应的原论文转录文件：
```bash
# 在 PDFs/<topic>/transcript/ 下查找
ls PDFs/<topic>/transcript/
```

### 步骤 2：提取笔记中所有关键内容

```bash
# 提取所有定理环境
grep -nE '\\\\begin\{(Theorem|Lemma|Proposition|Corollary|Definition)\}|\\\\label\{' <笔记文件>

# 提取所有 cite 引用
grep -nE '\\\\cite[^{]*\{' <笔记文件>

# 提取所有公式（检查是否有可疑的自行推导）
grep -nE '^\$\$|\\\[$' <笔记文件>
```

### 步骤 3：逐项验证

对于每个定理/引理：

1. **编号验证**：在原文搜索相同编号，对比内容
2. **公式验证**：逐符号核对
3. **证明验证**：检查是否"显然"、"容易验证"等主观表述（可能意味着捏造）

### 步骤 4：识别危险信号

以下情况可能是捏造或幻觉：
- ✗ "由...显然可得" → 但原文没有这个结论
- ✗ "类似地可证" → 但实际证明不显然
- ✗ 自行添加引理编号（如 Lemma A, Lemma B）→ 原论文不存在
- ✗ 证明中引用了不存在的引理
- ✗ 公式中变量与原文不一致

### 步骤 5：报告问题

```
=== 验证结果 ===

检查范围：<笔记文件>
原文来源：PDFs/<topic>/transcript/<paper>/

【编号验证】
✓ Theorem 2.3 - 与原文一致
✗ Lemma 2.2 - 论文中不存在此引理

【公式验证】
✓ 公式 (1) - 与原文一致
✗ 公式 (3) - 原文为 $c^w_{u,v}(\mathbf{y}, \mathbf{t})$，笔记为 $c_{u,v}^w(y, t)$

【证明验证】
✓ Refined Graham 证明 - 正确引用原文
✗ Theorem 1.1 证明 - 自行编造，未引用原文

【引用验证】
✓ \cite{Gr} - 正确
✗ \cite[ Theorem 1.1]{GX2025} - 论文中是 Theorem 2.3

总计：X 个问题，需要修正
```

## 修正原则

1. **必须对照原文**：所有内容必须有原文依据
2. **不能"显然化"省略**：如果原文有详细证明，笔记不能只写"显然"
3. **保持编号一致**：与原论文编号体系完全对应
4. **引用必须可查**：每个 cite 引用都必须在参考文献中找到

## 示例对话

用户: "检查这章笔记有没有幻觉或捏造"

助手:
1. 提取所有 Theorem/Lemma/Definition
2. 在原文中逐项核对
3. 发现 Theorem 1.1 的证明是自行编造
4. 报告问题并询问是否需要基于原文重写
