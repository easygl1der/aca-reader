# 阶段 5：人工审阅

## 目的

暂停 AI 工作流，等待用户对初稿进行审阅并提供反馈。

## 输入

- `drafts/v1_chapter{N}.tex`（阶段 4 输出）
- 编译后的 PDF

## 执行步骤

### Step 1：编译 PDF

```bash
cd notes/<topic>
./compile.sh
```

### Step 2：检查编译结果

- 编译成功：PDF 已生成
- 编译失败：使用 `latex-debug` 修复后重新编译

### Step 3：打开 PDF 供用户审阅

```bash
open -a Skim notes/<topic>/<topic>-notes.pdf
```

### Step 4：提供审阅指引

向用户展示审阅模板，要求提供结构化反馈：

---

## 📄 审阅请求

初稿 `drafts/v1_chapter{N}.tex` 已完成，PDF 已生成。

**请审阅以下内容**：

### 1. 结构与内容
- [ ] 引言动机是否清晰？
- [ ] 定义是否有充分的动机说明？
- [ ] 定理条件-结论是否清晰？
- [ ] 证明思路是否易理解？
- [ ] 示例是否有帮助？

### 2. 写作风格
- [ ] 是否遵循 Stein 动机优先风格？
- [ ] 是否有足够的历史脉络/背景说明？
- [ ] 语言是否流畅？

### 3. 数学符号
- [ ] 符号使用是否一致？
- [ ] 是否有不清晰的符号使用？

### 4. LaTeX 格式
- [ ] 公式排版是否美观？
- [ ] 是否有格式问题？

### 5. 附录
- [ ] 哪些推导应该移到附录？
- [ ] 附录是否完整？

---

## 反馈格式

请按以下格式提供反馈：

### 总体评价
[1-2 句话总结整体感受]

### 需要修改的部分

#### 1. [具体位置，如"引言第二段"]
**问题**：[描述问题]
**建议**：[修改建议]

#### 2. [具体位置，如"定理 5.2 的条件"]
**问题**：[描述问题]
**建议**：[修改建议]

### 新增内容建议
[是否有遗漏的重要概念/例子/联系]

### 删除内容建议
[是否有冗余或不必要的部分]

### 附录建议
[哪些推导应移到/移出附录]

### 其他意见
[其他任何意见]

---

## Step 5：等待用户反馈

**Skill 在此阶段暂停**，等待用户提供：

1. 口头反馈（转录为结构化文档）
2. 或直接写入 `drafts/feedback/review_v1.md`

### 用户反馈存储位置

```bash
mkdir -p notes/<topic>/drafts/feedback
```

创建 `notes/<topic>/drafts/feedback/review_v1.md`：

```markdown
# Review V1: Chapter 5 - Covariate Balance

## 总体评价
[总体评价...]

## 需要修改的部分

### 1. [位置]
**问题**：[问题描述]
**建议**：[修改建议]

## 新增内容建议
- [建议 1]
- [建议 2]

## 删除内容建议
- [建议 1]

## 附录建议
- [建议 1]

## 其他意见
[其他...]
```

## 验证

用户反馈提交后，确认：
- [ ] 反馈已保存到 `drafts/feedback/review_v1.md`
- [ ] 反馈结构完整

## 下一步

用户反馈提交后，传递给 **阶段 6：AI 迭代优化**
